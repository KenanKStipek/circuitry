- **`cof run` reports an unknown default adapter the way `cof check` does.**
  `run()` built the run-default adapter — `build_adapter(adapter_name=...)` —
  before preflight ran, so a typo'd default adapter (`adapter: opneai`, in
  the orchestration, a profile or config) with no per-effect override failed
  with the factory's raw `ValueError` instead of preflight's structured
  report. Preflight now runs before the run-default adapter is built, so
  `cof run` and `cof check` fail the same way for the same file.
