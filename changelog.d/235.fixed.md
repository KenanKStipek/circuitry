- **`cof run` reports a typo'd document-level default adapter the way
  `cof check` does.** `run()` built the run-default adapter —
  `build_adapter(adapter_name=...)` — before preflight ran, so a document's
  own `adapter: opneai` with no per-effect override failed with the
  factory's raw `ValueError` instead of preflight's structured report.
  Preflight now runs before the run-default adapter is built, so `cof run`
  and `cof check` fail the same way for the same file. Preflight only sees
  an orchestration's own `adapter:`/`provider:` references — a typo in a
  profile, `config.json`'s `default_adapter`, or `--adapter` still surfaces
  as the factory's raw error, in both `cof run` and `cof check`.
