- **`--events` gets a `decision` line.** Right after an `if` or `while`
  condition evaluates, both engines write one `decision` line: `path`, `kind`
  (`if`/`while`), `mode` (`cel`/`model`), the outcome (`branch` for an `if`;
  `continue`/`iteration` for a `while`), the CEL `values` a condition read
  (`unset` alongside, and `values_truncated` past 16 KiB, the same rule
  `report` data already follows), or a model condition's `answer`, and
  `error` when the condition raised.
