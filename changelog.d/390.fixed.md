- **A merge key inside a merged YAML mapping no longer raises a false
  duplicate-key error.** `load_yaml`'s duplicate-key check could see two
  copies of a key when a mapping that itself used `<<:` was merged into a
  shallower mapping constructed first — the shallower mapping's own merge
  expansion mutated the shared mapping's keys in place before its own
  duplicate-key check ever ran. The check now always runs against each
  mapping's own, unflattened keys, so an overriding `<<:` several layers
  deep loads the same as `yaml.safe_load`.
