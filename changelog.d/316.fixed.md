- **A trusted document's `runtime:` block merges into host config key by
  key.** `runtime.plugins.<name>` and `runtime.adapters.<name>` used to
  replace the host's whole value for that top-level key, so a document
  setting `runtime.plugins.sqlite.*` silently dropped every other host
  `runtime.plugins.*` setting, including a `runtime.plugins.shell.allowed_commands`
  pin, and a document setting one adapter's `timeout_seconds` dropped every
  other adapter's config. Both now merge one level deeper, so a document
  only overrides the keys it writes. `runtime.plugins.shell.allowed_commands`
  is also now a ceiling even for a *trusted* document: the effective
  allowlist is always the host's pin intersected with the document's own
  list, never the document's list outright — closing the one gap #308 left
  open.
