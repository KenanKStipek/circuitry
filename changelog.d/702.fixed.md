- **`osi`: a running agent session's tokens now count in every sum, share and
  the Signal.** Previously an agent's tokens showed only on its Store tile
  while it ran, and in a few places not even after it finished: the Totals
  row read only the finished prompts, a running agent's share on the Store
  table could read far past 100%, the Tape row of a finished agent showed no
  token figure at all, and the run summary's own Largest could miss it
  entirely. A step's tokens so far — exact once finished, else a prompt's own
  live figures or an agent's `meta.live.tokens_sent`/`tokens_received` (never
  `0` for a figure the engine hasn't reported, such as Claude Code's
  `tokens_received` mid-turn) — now feeds the Totals row, every share (the
  Tape detail pane, the Store table and Readings, capped at 100%), the Store's
  tiles, the Tape's own token column (agents included, not only prompts), and
  the run summary's Largest. The Signal screen plots an agent's tokens as they
  arrive, one column per observed increase, with only the remainder added at
  the agent's own end — so the sum of its columns always equals its final
  tokens — and its own Readings read the same columns.
