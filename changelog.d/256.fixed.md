- **`cof` commands show library warnings.** The CLI now attaches a stderr handler to the `circuitry` logger (`WARNING` by default, `INFO` under `--verbose` where a command has it), so a malformed global/project config, a failed tool param render, a plugin hook failure, or a skipped inline schema validation — previously swallowed by the library's `NullHandler` — reach the terminal. Stdout stays clean for `--json`/`--print`, and nothing the CLI already prints is duplicated.
