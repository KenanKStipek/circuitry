- **surrealdb: works with SDK 3, alongside SDK 2.** The `surrealdb` tool
  plugin and the SurrealDB persistence plugin run SDK 3's builder-style
  calls and give the same values, `meta` and error texts as on SDK 2 for
  every mode, including record ranges (`"table:1..10"`) and a
  database-scoped sign-in. One change on both majors: a multi-statement
  `query` now fails when any of its statements fails, where SDK 2 returned
  the first statement's result. A request that times out is reported as a
  timeout rather than as an unreachable server, and SDK 3's default
  30-second request timeout no longer cuts off a long query. The
  `surrealdb` extra allows either major (`surrealdb>=2,<4`).
