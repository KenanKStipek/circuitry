- **surrealdb: works with SDK 3, alongside SDK 2.** The `surrealdb` tool
  plugin and the `surrealdb` B-prime persistence runtime plugin now run
  SDK 3.x's builder-style `query` / `select` / `create` / `upsert` / `delete`
  calls (`.execute()`), matching SDK 2.x's values, `meta`, and error texts
  for every mode, a SurrealQL error, and a database-scoped sign-in. The
  `surrealdb` extra now allows either major (`surrealdb>=2,<4`).
