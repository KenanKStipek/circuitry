- **surrealdb: works with SDK 3, alongside SDK 2.** The `surrealdb` tool
  plugin and the `surrealdb` B-prime persistence runtime plugin now run
  SDK 3.x's builder-style `query` / `select` / `create` / `upsert` / `delete`
  calls (`.execute()`), matching SDK 2.x's values, `meta`, and error texts
  for every mode, a SurrealQL error, a database-scoped sign-in, a
  multi-statement `query` that fails partway through, and a record range
  target (`"table:1..10"`). A request that times out is now reported as
  having timed out rather than as an unreachable server, and the SDK's own
  default request timeout no longer cuts off a long-running query. The
  `surrealdb` extra now allows either major (`surrealdb>=2,<4`).
