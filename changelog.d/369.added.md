- **`agents/agent_loop`: an orchestration that is itself a tool-using agent
  (#369).** A `while` loop reads a transcript file, asks the model for one
  `prompt_type: json` decision (`{thought, tool, args, done, answer}`),
  dispatches it to one read-only tool inside `workdir` (list a directory, read
  a file, ripgrep, git status/log/diff/show), and appends the step to the
  transcript. It stops on `done` or after `max_steps`. An unknown tool or a
  path outside `workdir` is reported back to the model, not run. The document
  names no adapter or model. The transcript goes to a
  randomly named `$TMPDIR/circuitry-agent-loop-<uuid>.md` by default, never
  into `workdir`.
  [The agent loop](docs/agent-loop.md) explains a pass, the limits (cost per
  step, no memory beyond the transcript, the allowlists as the boundary) and
  how to add write tools.
