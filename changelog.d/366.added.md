- **`pi` and `claude_code` adapters: model calls through a coding-agent CLI's
  own login.** `adapter: pi` runs `pi -p --mode json` and `adapter:
  claude_code` runs `claude -p --output-format json` for one completion with
  the CLI's own tools off and no session saved, so a `prompt` effect can use a
  Claude subscription (or any provider pi is logged in to) instead of an API
  key. `claude_code` also passes `--strict-mcp-config`, so none of the
  user's MCP servers start. `prompt_type: json` works on both; on
  `claude_code` the effect's `schema` goes to the CLI as `--json-schema`
  (wrapped in an object when its top level is not one). Tokens land in
  `meta` and the CLI's reported cost in the new `meta.cost_usd`, which
  `runtime.last_run.totals.cost_usd` now sums. For adapter authors:
  `GenerateResult.cost_usd` is where an adapter reports that cost, and
  `GenerateOptions.json_schema` carries a JSON prompt's `schema` to an
  adapter that can ask its provider for matching output. The CLI runs in its own process
  group (a timeout or a cancelled run stops everything it started) and in an
  environment without the parent-session variables of a surrounding pi or
  Claude Code session and without `unset_env` (by default
  `ANTHROPIC_API_KEY` and `ANTHROPIC_AUTH_TOKEN`). A missing CLI is
  `binary:pi` / `binary:claude` in `cof check` and `cof doctor`; an auth or
  version error carries the CLI's own message. Configure `binary`,
  `default_model`, `thinking` (pi), `timeout_seconds`, `unset_env` and
  `extra_args` under `runtime.adapters.pi` / `runtime.adapters.claude_code`.
  See the [Orchestration Reference](docs/orchestration-reference.md#coding-agent-cli-adapters-pi-and-claude_code).
