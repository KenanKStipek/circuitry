- **idea-farm — focus adherence enforced and near-duplicate detection
  strengthened.** An owner review of ~160 banked ideas found runs ignoring
  their assigned focus and regressing to generic business-process templates
  ("world-building and fiction series" → "Retirement Savings Forecast"),
  which also defeated the farm's sharded dedupe: the same generic idea landed
  under several foci. `idea_generator.yml` now requires every focused prompt
  to name the domain's own artifacts and actors and to reject cross-domain
  office templates, and `farm.py` re-checks on harvest — an idea line sharing
  no content word with the focus phrase is dropped and counted per run as
  `focus_rejects`. Duplicate detection is no longer an exact normalized-title
  match (which missed "Drafting and tracking team meeting summaries" vs
  "Drafting and Tracking Meeting Summaries"): the new `IdeaIndex` keeps the
  exact key as a fast path and adds a global Jaccard similarity check over
  stemmed title tokens, tunable via `DUP_THRESHOLD` (default `0.7`). Both
  checks are pure-python token sets — no new dependencies. The state file
  format and `DATA_DIR` layout are unchanged, so an existing corpus resumes
  as-is under the stricter key.
- **idea-farm — `qa_corpus.py` corpus quality report.** Reports total vs
  effective-unique ideas, per-focus adherence, per-shape distribution and the
  top near-duplicate clusters over `DATA_DIR/all_ideas.jsonl`. Read-only:
  `--dedupe` writes `all_ideas.cleaned.jsonl` beside the master and never
  modifies it. Runs at farm boot when `QA_ON_BOOT=1`.
