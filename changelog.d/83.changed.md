- **idea-farm — focus adherence enforced and near-duplicate detection
  strengthened.** An owner review of ~160 banked ideas found runs ignoring
  their assigned focus and regressing to generic business-process templates
  ("world-building and fiction series" → "Retirement Savings Forecast"),
  which also defeated the farm's sharded dedupe: the same generic idea landed
  under several foci. `idea_generator.yml` now requires every focused prompt
  to name the domain's own artifacts and actors and to reject cross-domain
  office templates, and `farm.py` re-checks on harvest. The check targets
  that template regression rather than topical purity — downstream intake
  reclassifies domain itself, and a strict token-overlap rule was measured to
  reject legitimate on-focus ideas — so a line is dropped only when it is
  both off-focus *and* a match for a known office template not native to the
  run's focus (`focus_rejects`); merely off-focus lines are banked and
  counted as `off_focus` so adherence stays measurable. `FOCUS_CHECK` selects
  `template` (default), `strict` or `off`.
- **idea-farm — duplicate detection now survives a differing tail.**
  Duplicates were an exact normalized-title match, which missed "Drafting and
  tracking team meeting summaries" vs "Drafting and Tracking Meeting
  Summaries". The new `IdeaIndex` keeps that exact key as a fast path and
  adds a global Jaccard similarity check over two windows — the title, and
  the first `DUP_LEAD_WORDS` (default `8`) content words of the full line —
  taking the better score. The lead window covers the failure a 469-idea QA
  pass found dominant: pairs differing only in their trailing clause, which
  the title key folds together when the line carries a separator and misses
  entirely when it does not. `title_of` also recognises en-dashes, horizontal
  bars, double hyphens and substantial colon heads now. Both checks are
  pure-python token sets — no new dependencies. The state file format and
  `DATA_DIR` layout are unchanged, so an existing corpus resumes as-is under
  the stricter key.
- **idea-farm — `qa_corpus.py` corpus quality report.** Reports total vs
  effective-unique ideas, per-focus adherence, generic-template regressions,
  per-shape distribution with within-shape effective uniqueness, the number
  of near-dup clusters spanning two or more shapes (shape hints re-skinning
  rather than generating), and the top near-duplicate clusters over
  `DATA_DIR/all_ideas.jsonl`. Records banked before the `shape` field existed
  count as `default`. Read-only: `--dedupe` writes `all_ideas.cleaned.jsonl`
  beside the master and never modifies it. Runs at farm boot when
  `QA_ON_BOOT=1`.
