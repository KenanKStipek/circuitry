- **`termination.detail` is now written on the each-loop bounds-check error
  path too.** An `each` loop whose collection outgrows `max_iterations`
  under `on_error: break`/`continue` used to record `termination: {reason:
  error}` with no `detail`, only `meta.error` — unlike every other `error`
  termination, which carries both. CEL reading
  `state.prime.<loop>.value.termination.detail` now sees the same shape
  regardless of which path produced the error.
