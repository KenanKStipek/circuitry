- **A prompt effect's pre-dispatch `meta.model` now reflects a per-effect
  `model:` override.** It previously recorded only the run's default model at
  that point — even when the effect declared its own — and was corrected to
  the actually-resolved model only after a successful dispatch. An observer
  reading the node before dispatch (`on_effect_start`, `--explain-routing`)
  now sees the same model the adapter attempt chain is about to use. A new
  `meta.model_reason` (`explicit` or `default`) records which one it was.
