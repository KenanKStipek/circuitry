- **`electricity/` — a preview Rust runner for orchestrations.** A Cargo
  workspace (`electricity/Cargo.toml`, `crates/electricity`,
  `crates/electricity-cli`) lives alongside the Python package, sharing its
  version (`electricity/Cargo.toml`'s `[workspace.package] version` is kept
  equal to `pyproject.toml`'s, checked by a test and by the release
  workflow). The `electricity` binary prints `electricity <version>
  (preview)` and its usage; any run request reports that this preview
  cannot run orchestrations yet and points to `cof run`. From this
  repository's next tagged release on, the release workflow attaches
  static Linux (x86_64, aarch64) and macOS (aarch64) archives and a
  multi-arch container image (`ghcr.io/kenankstipek/electricity`) to the
  GitHub release, marked as a preview — see `electricity/README.md` and
  `electricity/DESIGN.md`.
