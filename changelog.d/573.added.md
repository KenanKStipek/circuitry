- **`--resume` continues inside an unfinished loop pass and `if` branch.** `cof run --resume`
  no longer reruns a named chain loop's unfinished pass from its first body effect: the pass the
  saved run stopped in reuses its body effects that finished without error and continues at the
  first one that didn't, by the same rule as at the top level. A `while` loop runs that pass
  without evaluating its condition again. An unfinished named `if` evaluates its condition again
  as before; when the condition selects the branch it took last time, that branch continues at
  its first unfinished effect, and when it selects the other branch, that branch runs from its
  start. A nested loop, `if`, `dynamic` or `use` that is the first unfinished effect of such a pass
  or branch resumes inside itself too, so with `runtime.state.record_children: true` a `use`
  continues inside its child at any depth. Tree-flow loops, unnamed loops and `if`s, `reflector`,
  and a pass with no saved record run from their start, as before. electricity has no
  `--resume` yet, so this applies to `cof` only.
