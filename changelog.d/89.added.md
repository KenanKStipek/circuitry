- **`cof validate` reports advisory warnings.** Deprecated alias spellings
  (`type: conditional`, `flow: cot`, …) and effects named after an effect type
  (`use`, `loop`, `if`, `dynamic`, …) are now named by the validator, with the
  path of the offending effect and the canonical spelling to use instead.
  Warnings are advisory only: they never change `ok` and never change the exit
  code. They surface through `cof validate` / `cof check`, the TUI Validate
  view, and the MCP `validate_orchestration` tool (whose result shape already
  declared a `warnings` key).
