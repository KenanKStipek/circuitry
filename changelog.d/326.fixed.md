- **A missing or malformed `CIRCUITRY_CONFIG` now names the variable.** Since the env var is an explicit config source like `--config` (#321), a bad path or file used to error with only the path, e.g. `Error: Config file not found: /tmp/x/config.json` — indistinguishable from a bad `--config` flag. It now reads `Error: CIRCUITRY_CONFIG points to /tmp/x/config.json, which does not exist; unset it or fix the path` (and the same for a malformed file), across `cof run`, `cof check`, `cof doctor`, every other config-reading subcommand, and the TUI's Doctor/Settings views. `--config`'s own wording is unchanged.
