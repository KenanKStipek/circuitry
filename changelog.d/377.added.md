- **`electricity-json`: a `json.dumps`-exact `Value` codec for the
  electricity preview runner.** A new crate
  (`electricity/crates/electricity-json`) writes and reads
  `electricity-value`'s `Value` as JSON, matching Python's `json` module
  exactly rather than `serde_json`'s defaults. The writer's `WriteMode`
  controls `indent`, `sort_keys` and `ensure_ascii` independently, so it
  covers both of `cof run --out`'s serializations byte for byte (plain
  `--out`: insertion-ordered, unindented; `--out --pretty`:
  alphabetically sorted, 2-space indent) plus the generic `default=str`
  call several callers need. Non-finite floats write
  `NaN`/`Infinity`/`-Infinity`; finite floats and non-`str` dict-key
  stringification reuse `electricity-value`'s own `repr(float)` rather
  than a second float formatter; big integers write their full decimal
  digits; `sort_keys` sorts the *original* keys with Python's own
  cross-type ordering rules (numeric keys sort numerically, never
  lexicographically) before stringifying, raising the way CPython's
  `sorted()` raises on an incomparable pair; a `Date`/`DateTime`/`Bytes`
  value raises exactly where `json.dumps` itself would unless that
  `default=str` mode is on, in which case it's stringified instead (keys
  still always raise: `default=` is never consulted for keys, in Python
  either). The reader has two entry points matching Circuitry's own two
  JSON call sites: plain `loads` (arbitrary-precision integers,
  `NaN`/`Infinity`/`-Infinity` literals, a repeated object key silently
  keeping only the last value, exactly like `json.loads`) and
  `load_json`, which every `.json` orchestration document goes through
  instead and raises on a repeated key, naming its dotted path word for
  word like Circuitry's own `core/json_load.py`. A golden corpus generated from
  CPython 3.11 and Circuitry's own loader
  (`electricity/scripts/generate_json_write_corpus.py`,
  `generate_json_read_corpus.py`) is checked in and replayed by the
  crate's tests, plus a property test round-tripping every float bit
  for bit through write-then-read; CI regenerates both corpora and
  fails if either drifts.
