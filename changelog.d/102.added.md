- **Deterministic complexity scorer.** `circuitry.core.complexity.score()` rates a
  prompt effect's complexity from seven mechanical signals — prompt size, distinct
  state references, `prompt_type`, output-schema shape, declared output size,
  structural position (nesting depth, loop body, reflector-generated) and an
  optional keyword-weight table. The function is pure: no adapter, no store, no
  config read, no clock, no randomness, so identical inputs always produce an
  identical number. Weights are an argument, not a config lookup. The result is a
  full breakdown rather than a bare number — every signal reports its raw
  measurement, the weight applied, its normalized value and its contribution in
  score points, and the contributions sum exactly to the total, so a surprising
  score can be argued with (`result.explain()` prints the table). Scores are
  normalized onto a fixed 0–100 range regardless of the weights, which keeps band
  tables portable. Prompts can be scored with a rendered prompt (`mode="rendered"`)
  or from the template alone (`mode="static"`, flagged `estimated=True`), and
  malformed input — unknown `prompt_type`, a non-mapping schema, junk weights —
  degrades to a warning instead of raising.
