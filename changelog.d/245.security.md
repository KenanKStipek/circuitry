- **Allowlists now guard everything a run builds, not just the top-level document.** `enabled_tools` / `enabled_adapters` used to be checked against the top document's text only, so a `use` child (`path:`, `ref:`, `inline:`), a reflector or decomposition plan, `--adapter`, the config's `default_adapter` and a profile's `provider` override all ran unchecked, and `--service-profile` dropped all three allowlists (and `environment`). `cof check` now follows `use` children statically; at run time each child is checked as it loads and every adapter and tool is checked as it is built. A project config discovered in the working directory may narrow a global allowlist but no longer widen or re-open it (`--config` / `CIRCUITRY_CONFIG` files are trusted as written), and `cof run` / `cof check` / `cof doctor` print the config sources they resolved.
