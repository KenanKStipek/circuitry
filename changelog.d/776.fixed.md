- **`cof run --last`/`electricity run --last` now work from another directory.** The stash records the absolute working directory the run itself used; a replay from elsewhere resolves the stashed, relative `orchestration`/`--config` paths against that directory instead of the replaying invocation's own cwd, and prints one line naming what it resolved. A stash written before this change still replays, resolved against the current directory exactly as before.
- **A `--last` stash that can't be parsed now gives a one-line error naming the file, never a traceback**, at the same exit code `--last` already uses for "no previous run" — on both engines.
- **`scripts/install.sh` now requires Python 3.10**, matching the package's own `requires-python`; it previously accepted 3.9.
- **A regression test now renders every `cof`/`electricity`/`osi` command's `--help` and fails if any of them cites an issue number.**
