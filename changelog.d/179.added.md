- **`learn/surrealdb_roundtrip` curation example.** Create a record with the
  `surrealdb` tool, select it back by the id `create()` returned, and assert
  equality deterministically — the raw SDK responses are reduced to a
  comparable `{name, score}` view with the `json` tool, then compared with
  `if`/CEL. No LLM involved; run it with
  `cof run learn/surrealdb_roundtrip -e name=Ada -e score=10`. The
  `docs/plugins/surrealdb.md` doc page (added in #181) is now linked from the
  README tool table.
