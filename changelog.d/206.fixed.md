- **`use` cycle detection no longer false-positives under `flow: tree`.** `_use_call_stack` was one list held in `runtime_config`, a dict shared by every runtime in a run; tree-flow iterations execute concurrently on a `ThreadPoolExecutor`, so sibling iterations `use`-ing the same child pushed the same identity onto that shared list and saw each other as ancestors — every iteration after the first raised a false `RecursionError`, making parallel composition of `use` inside `each`/`flow: tree` (or a decomposition chunk that itself runs in a tree loop) unusable. Both `use` and runtime decomposition now derive the call-stack per call-path — a snapshot of the parent's stack plus the current identity, handed down through the child's own `runtime_config` — instead of mutating shared state, so concurrent branches no longer collide, at any nesting depth. Linear self/mutual-recursion detection (`A → B → A`) is unchanged.
