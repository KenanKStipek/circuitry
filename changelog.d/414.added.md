- **The `agent` tool's usage counts in the run totals.** `ToolResult` gained
  optional `tokens_sent`, `tokens_received` and `cost_usd` fields; `ToolRuntime`
  copies a value that isn't `None` into `meta.tokens_sent`, `meta.tokens_received`
  and `meta.cost_usd` — the same fields a `prompt` effect sets — summing a
  retried tool's attempts into `tokens_sent_total`/`tokens_received_total` the
  same way a retried prompt's do. The `agent` plugin fills them with the
  session's totals over every turn, including a repair turn; `meta.raw.tokens`/
  `meta.raw.cost` are unchanged. `runtime.last_run.totals` and the `dynamic`
  tree's live token sums now include an `agent` effect's usage — in a chain, a
  loop, or a `use` child — with no special case. Every other tool provider is
  unaffected: `None` means no new meta keys appear.
