- **A run's label.** A top-level `label:` Mustache template in an
  orchestration document, rendered once against the run's resolved
  `input.*` when it starts, or `--label TEXT` on `cof run` and
  `electricity run` — literal text that wins over the document's own.
  Either way the result is cleaned (whitespace collapsed, control
  characters and escape sequences dropped, trimmed, cut at 64 characters)
  before it lands in `--events`' `run_start` and `runtime.last_run` in
  `--out`/`--live-state`, present only when the run actually has one. A
  malformed template is a `cof check` error; a render failure that reaches
  a run anyway warns once and the run continues with no label. `--resume`
  re-renders the document's label from the resumed inputs unless `--label`
  is given, and only the root document's own `label:` counts — a `use`
  child's is never surfaced. See [Labelling a
  Run](docs/orchestration-reference.md#labelling-a-run).
