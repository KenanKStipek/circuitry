- **Conformance suite.** `tests/conformance/` runs the Python engine fresh on
  a set of small, model-free documents and compares the result with a
  committed `expected.json` under a shared normalizer (timestamps, run ids,
  durations, and machine-local paths normalized; Circuitry's own error
  messages compared byte-for-byte). First cases cover the M0 acceptance set
  (C2, C3, C6, C23, C27, and the `if` half of C7) from
  `electricity/docs/spec/runtime-semantics.md`. `scripts/generate-conformance-cases.py
  --check` is now part of the verification gate and fails when a committed
  expected state is stale. An electricity runner exists alongside it, invoking
  the `electricity` binary per case and skipping with a clear reason while the
  preview build cannot run orchestration documents yet.
