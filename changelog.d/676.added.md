- **electricity streams prompt replies too.** Ollama, the OpenAI-compatible
  adapter family, `openai` and `anthropic` stream by default on electricity
  the same way they already do on `cof` (#674): the same request bodies,
  the same assembled result for a success, a dropped-connection failure, or
  a mid-stream error; `runtime.adapters.<name>.stream: false` restores the
  old non-streamed request on either engine. A running prompt effect
  publishes `meta.live` and `--events`' own `progress` line on electricity
  too, and its `scripted` adapter now delivers a reply's `chunks` as
  deltas instead of folding them straight into the final text.
