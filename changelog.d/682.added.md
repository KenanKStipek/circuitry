- **electricity runs the size trigger for decomposition.** A prompt effect
  whose rendered input exceeds its token budget now splits and runs on
  electricity the same way it does on `cof run`: the same pure splitter
  (list items, mapping entries, text at its own structure), the same
  split-reference picker, the same generated `loop`+`prompt` (and, for a
  reduce merge, `prompt`) plan — byte-identical YAML, down to the parts never
  appearing in it — and the same native `join`/`concat` merge or
  author-supplied `split.merge.template` reduce prompt. `runtime.complexity.
  splitting` and a prompt's own `split:` block no longer refuse the document
  up front.
