- **`flow: tree` dynamics no longer deep-copy the whole run context.** A
  `flow: tree` dynamic's children now get a cheap shallow overlay of the run
  context instead of a `deepcopy(ctx)`, the same change #309 made for tree
  `each` loops — cost no longer scales with the size of the run state, which
  matters most for a tree dynamic that runs once per pass of an enclosing
  loop. The "snapshot from dynamic start, not sibling writes" guarantee is
  unchanged: every write still lands in a branch's own isolated store, never
  in the shared context.
