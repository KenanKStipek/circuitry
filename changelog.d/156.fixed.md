- **Test suite is now hermetic to the developer's global config.** A real `~/.config/circuitry/config.json` (e.g. one with a restrictive `enabled_adapters` allowlist) used to leak into any test that went through `resolve_config()`, `find_config_path()`, or the CLI's last-run stash, since `circuitry.cli.config`/`last_run`/`app`/`setup` each bind `GLOBAL_CONFIG_DIR`/`GLOBAL_CONFIG_PATH`/`LAST_RUN_PATH` from `Path.home()` at import time — 25 tests failed on any machine with such a file, though CI stayed green because runners have no global config. An autouse fixture in `tests/conftest.py` now redirects all of those bindings to a per-test temp directory; tests that intentionally exercise config discovery tiers opt out with `@pytest.mark.real_config_discovery`.
