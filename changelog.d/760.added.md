- **`electricity run` shares cof's `--last`/`--resume last` stash.** `electricity run`
  writes `~/.config/circuitry/last-run.json` after every run, successful or not, with
  the same keys, key order, JSON formatting and `-e` redaction `cof run` uses.
  `electricity run --last` replays the stashed run's own arguments, and
  `electricity run <doc> --resume last` resumes from that run's `--out`, with the
  same checks and messages as `cof run`: no previous run, an unreadable stash, a
  different orchestration, no `--out`, a gone `--out` file, and a redacted `-e`
  value refusing `--last`. A stash either engine wrote replays on the other.
