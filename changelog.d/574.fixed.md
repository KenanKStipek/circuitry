- **An interrupted loop keeps its finished passes for `--resume`.** A named loop stopped by
  Ctrl-C, SIGTERM or SIGHUP, or by a cancelled run, now records what it records on a failure:
  `meta.completed_passes`, `meta.completed_at`, and the interruption as `meta.error`
  (`Interrupted (Ctrl-C/SIGINT)`, `Interrupted (SIGTERM)` or `Interrupted (SIGHUP)`). It then
  re-raises the interrupt unchanged, so the exit code, cleanup and `finally:` behave as before.
  `cof run --resume` now continues at the first pass that didn't finish instead of running the
  finished passes again. This applies at any depth: nested loops, and a loop inside a `use`
  child with `runtime.state.record_children: true`. electricity's loop records the same thing
  when its run is cancelled.
