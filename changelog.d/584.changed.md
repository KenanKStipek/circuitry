- **`cof run --resume`/`electricity run --resume` rerun a finished `use`
  whose inputs changed.** A finished `use` whose inputs, resolved against
  the resumed run's own `-e`/`--state` values, no longer match its recorded
  `meta.inputs` now reruns, along with everything after it in the same
  chain. A resume whose run inputs differ from the saved run's warns once,
  naming each changed input; one with unchanged inputs behaves as before.
