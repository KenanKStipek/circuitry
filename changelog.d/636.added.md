- **The `agent` tool publishes a live summary while a session runs.** The CLI's own output is now read as it arrives, through a reader thread `core.cancellation.run_tracked` hands each line to, rather than only after the whole call finishes. While running, the effect's node gains `meta.live` — numbers, times, ids, the model name and tool names only, never prompt/reply/thinking text, tool arguments, tool output, file contents, the environment or error text — published through `Store.set` at most once a second, so `--live-state` shows a multi-minute session's turns, tool calls, the tool currently running, token and cache usage so far, context size and diff stats instead of a blank bar. A retried attempt gets a fresh one carrying `earlier_attempts` from before it; the repair turn continues the same one; it is removed once the attempt ends, except when the run itself is interrupted, when it is left as the only record of that attempt's session id and transcript. `meta.raw` gains `context_tokens`, `context_window`, `tool_counts`, `turn_tokens`, `files_changed`, `lines_added` and `lines_removed` once the attempt ends.
