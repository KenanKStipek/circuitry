- **Narrower reference-library ranges.** `pyyaml`, `jsonschema`,
  `jsonschema-specifications`, `referencing`, `chevron`, `python-dotenv`,
  `cel-python`, `lark`, `google-re2` and `pendulum` are now bounded to the
  minor release CI's conformance suite runs against
  (`electricity/scripts/generator-constraints.txt`), instead of an open
  `>=` range — so `pip install circuitry-cof` can no longer resolve a
  library version the suite never ran against.
- **One explicit CEL nesting-depth limit.** A `mode: cel` expression
  nested deeper than 32 levels (parentheses, calls, list/map literals,
  member-access/index/method-call links, binary operators, `&&`/`||`
  links and prefix `!`/`-`) is refused with "expression is nested too
  deeply (limit 32)" as soon as it is compiled, before any effect
  evaluates it — the same limit, the same message and the same phase on
  cof and electricity, regardless of the expression's own shape or
  Python version. Replaces cof's old limit (wherever CPython's own
  recursion happened to give out) and electricity's seven separate,
  per-shape caps.
