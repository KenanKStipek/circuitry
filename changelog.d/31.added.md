- **TUI Profile editor (`9`)** — build named profiles without YAML surgery. Pick an orchestration, and it is compiled through the validate-only path and rendered as an effect tree: every effect gets a provider/model picker (configured adapters and their models, with a free-text fallback) and an enabled toggle, with reflectors flagged and containers noting that an override reaches their whole subtree. Panels cover run-level `adapter`/`model` defaults, `inputs`, and the `persistence` target (backend dropdown plus that backend's keys). Save, duplicate and switch named profiles into `<orchestration_dir>/profiles/`, with a dirty-state indicator and confirm-on-leave; `Ctrl-R` hands the orchestration and profile to the Run view pre-loaded. Overrides naming effects the orchestration no longer defines are listed as orphans with a one-key cleanup (`Ctrl-O`), and toggling a conditional's `if` or a loop's `while` is refused in the profile validator's own words.
