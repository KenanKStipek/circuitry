- **`surrealdb` runtime plugin.** `circuitry.runtime_plugins.surrealdb` persists
  each run as a `runs` row plus one `effects` row per effect — the same
  run/effect shape as the SQL B-prime schema, written through SurrealQL via the
  official SDK rather than a DBAPI cursor (the same driver-model split as the
  bundled `clickhouse` plugin). `environment: prod` omits `effects.raw`
  (full provider responses) under the same `store_raw` cascade as the SQL
  dialects; connection/auth (`SURREAL_URL` / `SURREAL_NAMESPACE` /
  `SURREAL_DATABASE` / `SURREAL_TOKEN` or `SURREAL_USER` + `SURREAL_PASS`)
  mirrors the `circuitry.plugins.surrealdb` tool plugin's conventions. Install
  with `pip install circuitry-cof[surrealdb]`; documented in
  `docs/runtime-plugins.md`.
