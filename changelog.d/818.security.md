- **comfyui's curl calls, every tool's `raw["url"]` and cyberdiner's check
  follow the shared URL rules.** comfyui's image download, reference-image
  upload and reachability check now go through the same curl `--config` path
  as every other curl call, so `base_url` never appears on curl's command line,
  and they check the URL (scheme, port, proxy) before any I/O or file read.
  The `raw["url"]` a tool returns (`http`, `web_search`, `weather`, `webhook`,
  `web_fetch`, `playwright`, `screenshot`, `rss`, `surrealdb`) no longer
  carries the URL's userinfo or credential query values, on both engines.
  cof's `cyberdiner` check reports a schemeless `expo_url` as a `host:` entry
  instead of raising urllib's "unknown url type".
