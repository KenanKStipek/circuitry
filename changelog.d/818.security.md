- **`comfyui`'s own curl calls, the `http` tool's `raw["url"]`, and cyberdiner's `check()` now follow the shared URL rules.** `comfyui`'s image download, reference-image upload and reachability check used to pass `base_url` to curl as a bare argument (visible to `ps`) and skip Circuitry's own scheme/port/proxy checks; all three now route through the same `--config` path every other curl call here uses, checked before any I/O or file read, with a new `-F`/multipart form-field option for the upload. The `http` tool's `raw["url"]` carried the full request URL, userinfo included, even though every other surface that names a request URL redacts it — it's now redacted the same way on both engines. `cof`'s `cyberdiner.check()` built its probe request before checking the configured URL, so a schemeless `expo_url` raised urllib's own bare "unknown url type" instead of being reported as an actionable `host:` entry; the check now runs first, on both engines.
