- **A `while` loop's `mode: cel` condition can now read `state.iter.index`.**
  `cof check` already allowed it, but the loop only set the `iter` binding
  once a pass was about to run — after that pass's own condition check had
  already evaluated — so the condition always saw the previous pass's index,
  one check behind, and a condition like `state.iter.index < 3` never behaved
  as written. The condition now sees the number of passes that have
  *completed* so far: `0` on the check before the first pass, `N` once `N`
  passes have run.
