- **The `agent` tool keeps `meta.raw` when a turn fails.** A turn that times out or
  the CLI fails after the session already has an id (a `session` param, or an
  earlier successful turn in the same effect) or a transcript exists now ends
  the effect as an ordinary tool failure (`ok: false`, so `on_error` and
  retries behave exactly as before) whose `meta.raw` still carries the same
  keys a success has — `session_id` for a later effect's `session` param,
  `transcript` to inspect — plus `timed_out: true` on a timeout. `meta.error`'s
  text is unchanged. Previously that context only reached the failure message
  as prose; a turn that fails before either exists still raises, as before.
