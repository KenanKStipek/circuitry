- **Documentation: `resume: restart` and `CIRCUITRY_SYSTEMONE_URL`.** The
  reference no longer says a restarted scope's saved children are unreadable
  (they are only not reused). The `systemone` page says a document run by path
  still wins over `CIRCUITRY_SYSTEMONE_URL` with its own `base_url`, as with
  `CIRCUITRY_COMFYUI_URL`. electricity's spec describes `resume: restart` (its
  IR must carry the key once electricity has `--resume`) and lists
  `CIRCUITRY_SYSTEMONE_URL` among the config overlays as `cof` only.
