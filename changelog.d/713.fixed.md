- osi's Combined Signal (`u` on All) now scales its own vertical layout at
  every terminal height instead of only the frame's own 180×48: with less
  height the trace shrinks first (down to a floor of 9 rows: 5 above the
  axis, the axis, 3 below), then the legend's own blank rows, then the Per
  Run table's own blank rows, while every run always keeps its own legend
  row, the Per Run table always keeps its header plus at least `min(runs,
  3)` scrollable rows with the cursor kept in view, and Readings always
  keeps its own four lines; with more height the extra rows all go to the
  trace. The screen's own minimum height now grows with the run count
  instead of a fixed floor that left most of a 120×30 terminal unusable
  (only one legend row, no visible Per Run or Readings rows). A Readings
  line too long for a narrower-than-golden panel now wraps instead of
  truncating mid-word.
