- **Prompt composition.** A new `type: yield` effect renders a template and stores the text with no model call. A top-level `prompts:` map declares named prompts (text or `{file: <path>}`), and `{{> name}}` splices a declared prompt or a `yield`/text-`prompt` effect's own text into a prompt template or messages, a declared prompt, a prompt file, a tool's `params`/`prompt`/`params_json`, or a `use` effect's `inputs`/`inline` — verbatim, never re-rendered, with one trailing line break dropped. `cof check` rejects an unknown name, a name that is both declared and an effect, an effect that is neither `yield` nor a text `prompt`, and a cycle among declared prompts. A prompt file is confined to the document's project (or, for a library document, that source's own tree), with symlinks resolved before the check.
