- **`cel` tool: a step that computes a value with CEL.** `provider: cel` evaluates `params.expr` against the bindings an `if` at the same position sees (`state.input`, `state.prime`, `state.runtime`, and an enclosing loop's `each.as` and `iter`) and writes the result as JSON: lists, maps (in their key order), strings, numbers, booleans and `null`, with timestamps and durations as ISO 8601 strings. An unset `state.` path gives `null` and a warning, as in `if`, and `strict: true` fails the effect instead; an optional `schema` must match the result. `cof check` parses the expression and checks the names it reads, so the params are literal: never Mustache-rendered, no `{from: ...}`, no `params_json`. It needs no capability and does no I/O. electricity refuses the plugin like the other cof-only plugins.
