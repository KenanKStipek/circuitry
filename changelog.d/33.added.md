- **TUI Chat view (`8`) — build an orchestration by talking to it.** A light seed form (name, category, one-line goal) opens a conversation with `curation/agents/wizard.yml`: every message re-runs the wizard on a worker thread with the accumulated transcript and draft, its reply lands in the conversation, and its YAML lands in a side pane with a live verdict from the same validator `cof check` runs — green tick or the error list. A green draft saves to a file, or into the local library as `<category>/<slug>.yml` plus a generated `manifest.json` entry that passes the curation manifest schema, so `cof run <name>` finds it. An invalid draft cannot be saved by any route. `Ctrl-S` / `Ctrl-G` / `Ctrl-R` (or `/save`, `/library`, `/run`) save and hand the saved file to the Run view via `app.pending_run`. The view never touches an adapter itself — it drives `api.run_orchestration`, which now takes an `adapter=` argument so a host (or a test) can supply its own.
