- **Loops no longer cap at 100 iterations unless you set `max_iterations`.** The runtime used to default every loop's `max_iterations` to 100 without saying so — an `each` loop over more items than that, or a `while` loop whose condition never converged, silently stopped short and left the run green. `max_iterations` is now `None` (no cap) unless the orchestration sets it: an `each` loop runs every item in its collection, and a `while` loop runs until its condition is false. A loop node's `meta` no longer records a `max_iterations` it was never given. `max_iterations` (and #209's fail-fast/`truncate` behavior) work exactly as before whenever it *is* set. The schema's `max_iterations` minimum is now `1` — `max_iterations: 0` is a schema error (`cof check`) instead of silently becoming 100.
