- **electricity: CEL nesting limits now match Circuitry's own boundaries per
  expression shape**, measured directly against Circuitry's real evaluator in
  three call contexts (a top-level `if`, inside a `while` chain loop, inside a
  `use` child). Operator/accessor chains (arithmetic, relational,
  member-access, index, method-call) now accept up to 242 links, up from 64;
  bracket nesting (parentheses, list and map literals, global function calls)
  is capped at 48, matching Circuitry's own tightest measured floor. A
  rejection for either now reads in Circuitry's own `"CEL evaluation failed
  for ...: "` form instead of a bespoke message. `electricity-template`'s
  "Known divergences from chevron" list now documents its own section-nesting
  cap (64) the same way. `Value::depth()` and CEL's own `Value` conversion no
  longer disagree by one on a value whose innermost container is empty.
