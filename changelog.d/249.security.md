- **Orchestrations can no longer set host-level runtime settings.** A
  document's own `runtime:` block now contributes only `runtime.complexity`
  and `runtime.state`; any other key (`adapters`, `plugins`, `persistence`,
  `library`, `mcp`, ...) comes only from config.json and is ignored with a
  warning naming the key in `cof run` and `cof check`. A document's top-level
  `plugins:` list only loads modules config already lists in `plugins` or
  `enabled_plugins`. A host that runs only its own documents can restore the
  old behaviour with `trust_orchestration_runtime: true` in config.json or
  `CIRCUITRY_TRUST_ORCHESTRATION_RUNTIME=1`. `cof run` and `cof run-library`
  now print run warnings on stderr, including for failed and piped runs.
