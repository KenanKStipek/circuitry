- **Bundled decomposition planner (`agents/decompose`).** Takes one over-complex
  prompt and returns an orchestration that does the same job as a fan-out over
  the natural units of the work plus a single merge step. Planning is one prompt
  effect (`plan`), so pointing it at a purpose-built planner model is a profile
  key rather than a rewrite; the emitted YAML is checked with the `validate_yaml`
  tool and revised in a bounded loop, and the same loop enforces the chunk budget
  from `runtime.complexity.decomposition.max_chunks` — an over-wide fan-out is
  revised even when it validates. The merged result is always exposed at
  `prime.merge.value`, reported as `result_path` so callers need not hardcode it,
  and `done` is a CEL gate over validity and chunk count rather than the model's
  own verdict. Tests measure the simplification with the `core.complexity` scorer
  instead of assuming it: every emitted chunk, and the merge step, must score
  below the source prompt.
