- **The Guidebook — `docs/guidebook/`.** The README is now the short tour (install, first run, mental model, repository layout), and the exhaustive tour moves to a fourteen-chapter guidebook in three acts — Basics (Prompt, Dynamic, State, Configuration, Errors), Cybernetics (If, Loop, Reflector), and the machine in the world (Composition, Complexity, Decomposition, Surfaces, Tools and persistence, the whole meal) — plus the formal grammar as an appendix. One dinner-party example runs through every chapter. Every YAML block in the guidebook is executable doctrine: `tests/docs/test_guidebook_examples.py` validates each positive example with the compiler and proves each anti-pattern marked ✗ fails validation (or, marked ⚠, produces the advertised warning). `scripts/build-guidebook.py` assembles the chapters into `docs/guidebook/circuitry-guidebook.pdf` and `.epub`, both committed. `docs/index.md` is rewritten as the documentation map.
