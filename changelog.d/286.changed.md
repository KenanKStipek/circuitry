- The README and the Guidebook now teach through one running example of an agent at work: an issue-to-fix agent that triages an issue, gathers context with `ripgrep`, `git` and `gh`, plans a fix, patches the code until the tests pass, and opens a pull request. It replaces the dinner party. Chapter 14 is now [Issue to pull request](docs/guidebook/14-issue-to-pull-request.md) (it was *The whole meal*), and every behaviour the chapters describe was re-run against a scripted model, stand-in tools and a throwaway repository.
