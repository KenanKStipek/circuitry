- **`--events`: an unnamed `flow: tree` loop's `dispatch` no longer has a
  literal `None` in its `path`.** `Store.fire_concurrent_dispatch` passed an
  unnamed loop's `self.defn.name` (`None`) straight into `effect_path`,
  whose f-string stringified it, landing a path like `prime.None` that
  named no real node — any consumer (oscilloscope included) saw a node that
  didn't exist. Since an unnamed tree loop's passes already run directly in
  the enclosing container (it is transparent, with no node of its own), its
  `dispatch` now carries that container's own path instead — the same path
  every other event it fires already uses. `electricity` reproduced the old
  behaviour on purpose (#466) and now matches.
