- **A model-mode `if`/`while` with no separate `prompt` effect no longer
  crashes with a misleading "tool-only orchestration" error.** `mode: model`
  is the compiler's default for an `if`/`while` condition, but the check
  that decides whether a run needs a real adapter only counted
  `PromptDefinition` instances, so a document whose only model use was a
  model-mode condition got the no-op adapter and crashed the moment the
  condition called `generate()` — worse, under `on_error: continue`, the
  failure was silently swallowed and the `else` branch taken with no
  explanation. A document with a model-mode condition now gets a real
  adapter — and preflight checks it — the same as one with a `prompt`
  effect.
