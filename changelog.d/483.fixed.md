- **A `use` child's own `flow: tree` loop now reports its `dispatch` event
  (and MCP's `branch_settled`) at the same absolute path its `start`/`end`
  events use.** It previously carried the child store's own unnamespaced
  `prime.<loop>` path instead — colliding with a parent loop of the same
  name, and leaving an observer that keys dispatch information by path (such
  as `oscilloscope`) unable to attach a child loop's branch counts to its
  node.
