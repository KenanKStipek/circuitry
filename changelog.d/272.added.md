- **`finally:` cleanup blocks.** The document root and any `dynamic` effect
  can now carry a `finally:` list of cleanup effects, run after the main
  `effects` complete — on success, on failure, and best-effort on a
  Ctrl-C/cancellation — always sequentially regardless of the enclosing
  `flow`, seeing state as it stands. A `finally` failure never hides the
  main `effects`' own failure (reported as-is, with the `finally` failure
  added as a second note, `meta.finally_error`); on an otherwise-successful
  run, a `finally` failure fails it too, unless that `finally` effect has
  its own `on_error: continue`/`skip`. A `use` child's own root `finally:`
  runs when the child finishes. Replaces the former workaround of marking a
  cleanup step's predecessor `on_error: continue` just to guarantee the
  cleanup always ran.
