- **A `flow: tree` each-loop no longer deep-copies the whole run context per
  item.** Each parallel iteration used to get a full `deepcopy(ctx)`, kept
  for the loop's whole duration — quadratic in time and memory for a large
  collection or a large run state. It now gets a cheap shallow overlay, the
  same shape the `chain` path already builds; body effects already write
  only into their own isolated per-iteration store, so a shared nested dict
  is read, never mutated in place.
