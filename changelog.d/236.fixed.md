- **Saved state: every writer stores a loop's `last` by reference.** `--out`/`--print`/`Store.dump_json`/the `--live-state` mirror already wrote a loop's `last` as `{"$ref": "iter_N"}` instead of a second full copy of its final pass (#220); persistence backends (postgres, sqlite, mongodb, jsonl-file), the runtime-plugin snapshot exporters (s3, gcs, azure-blob, r2, mongodb, dynamodb, firestore, couchdb, elasticsearch, opensearch, redis, memcached), and MCP run-state responses now write the same reference form. Everything that reads saved state back already relinks it, so readers see the same state as before.
