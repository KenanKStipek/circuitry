- **A running subprocess tool publishes its latest output.** `shell`,
  every plugin built on the shared subprocess helper (`awk`, `gh`,
  `imagemagick`, and the rest), and `ffmpeg` (not every plugin that runs a
  program — not the `agent` tool, which already has its own `meta.live`,
  nor `http`, which has no process) now carry `meta.live` while they run:
  the last 20 lines read so far on each of stdout and stderr, the current
  line shown as soon as it's read even before a newline ends it, cut to
  stay within 4 KiB of UTF-8 and decoded with invalid bytes replaced, plus
  the running raw-byte count on each — published at most once a second,
  removed before the node's final write so a finished node is unchanged.
  With no `--live-state`/state observer wired, the overhead is unchanged
  from before this feature. `osi`'s detail pane shows it as
  `── Output (live) ───`/`── Errors (live) ───` sections while the step is
  still running.
