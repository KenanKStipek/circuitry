- **A running subprocess tool publishes its latest output.** `shell` and
  every other tool plugin that runs a program (`awk`, `gh`, `imagemagick`,
  `ffmpeg`, and the rest — not the `agent` tool, which already has its own
  `meta.live`, nor `http`, which has no process) now carries `meta.live`
  while it runs: the last 20 lines of each of stdout and stderr (at most
  4 KiB), decoded with invalid bytes replaced, plus the running byte count
  on each — published at most once a second, removed before the node's
  final write so a finished node is unchanged. `osi`'s detail pane shows it
  as `── Output (live) ───`/`── Errors (live) ───` sections while the step
  is still running.
