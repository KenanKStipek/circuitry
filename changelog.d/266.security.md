- **A live, metered CyberDiner test can no longer run by accident.** `tests/integration/test_cyberdiner_live.py`'s `live` fixture previously treated `CYBERDINER_EXPO_URL`/`CYBERDINER_TOKEN` being set in the environment — for any reason — as consent to spend a real request against the production CyberDiner service, with no further confirmation. It now requires a third, distinct opt-in, `CIRCUITRY_LIVE_TESTS=1`, in addition to credentials; the documented `CIRCUITRY_RUN_INTEGRATION=1 pytest -m integration tests/integration/` command stays bounded to local/offline-reachable backends. See `CONTRIBUTING.md` and the module docstring for the full opt-in command.
