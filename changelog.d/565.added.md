- `shell` and the subprocess-based tool plugins (`git`, `gh`, `ripgrep`, `docker`, `pytest`, ... — every one built on the shared subprocess base) accept an optional `parse: json` param: `value` is then the parsed JSON of stdout (object, array or scalar) instead of the text, with the raw stdout still on `meta.stdout`. Empty or invalid stdout fails the effect with the exit code and the beginning of stdout; with `allow_nonzero: true` a nonzero exit's stdout is parsed the same way and `meta.exit_code` stays visible. Works on both engines (#565).
