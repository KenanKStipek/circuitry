- **`dynamic` effect fields now take effect.** `max_concurrency` bounds the worker pool on `flow: tree` (unset still runs every child at once); `stop_on_error: true` cancels tree children that have not started yet once one fails; `on_error: skip`/`continue` isolate a failing dynamic from its own parent instead of always propagating; `labels` are recorded on `meta.labels`. Previously all four were schema-valid and documented but silently dropped by the compiler.
- **`reflector.max_effects` is now enforced at run time**, not just suggested to the planning model. A generated plan with more top-level effects than the cap is treated as an invalid plan — the same path a plan that fails to parse takes — naming the count and the cap. Plans are never truncated to fit.
