- **`cof check` now compiles a `use: path:` child the same way a run would.** A child outside its own project boundary (an escaping `{file: ...}`), with a schema error, or failing two `use: path:` levels down, now fails the root's own check — named by its own path relative to the root, with the same error message a run would raise reaching it, in both text and `--json` output — instead of passing the root silently. A legacy `use: orchestration:` child resolved through the library runs limited in the same walk, same as the run itself treats it once it falls back.
