- **A host pin for the `service` tool.** `runtime.plugins.service.allowed_commands` bounds which commands `service`'s `start` may run, matched the same way as the `shell` plugin's own pin: an argv command's `command[0]` must be a bare name in the pin, and `shell: true` is refused unless the pin names `sh` (which then admits any string — the pin is all or nothing in shell mode). The refusal happens before anything starts: no state directory, no port claim, no process. It is a ceiling even for a trusted document's own `runtime.plugins.service.allowed_commands` (the shell pin's own rule, now shared by `service`'s pin too), and a limited document's `runtime:` block cannot set it at all. Without a pin, `service` behaves exactly as before. Ported to `electricity` with the same denial text.
