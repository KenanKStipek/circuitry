- **MCP plugin `parse` modes.** `parse: auto` now attempts to JSON-decode
  the joined text content when `structuredContent` is absent (many real MCP
  servers return JSON as a single text block instead of structured content),
  falling back to plain text when it isn't valid JSON or isn't an object/array
  — structured → JSON-in-text (object/array only) → text. `parse: json` no
  longer raises on an `isError` response whose text isn't JSON; it returns
  `value: None` and surfaces the error via `stderr`/`exit_code: 1` like the
  rest of the error contract, raising only when a *successful* response
  fails to parse.
