- **`--verbose` now labels a prompt effect with the adapter it actually
  dispatches to, not the run's default.** A per-effect `provider:` (in YAML
  or overlaid by a profile's `effects.<path>.provider`) previously showed the
  run-default adapter in the start/running/completion lines, only becoming
  correct by accident when the primary provider failed and the run default
  answered as a fallback. The verbose label is now derived from the same
  attempt chain dispatch uses, and the completion line names whichever
  adapter actually answered — with the failed primary still visible (e.g.
  `ollama ✗ → cyberdiner · cheap`) — so it always agrees with `meta.adapter`.
