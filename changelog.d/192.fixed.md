- **Curation examples now use `{{input.*}}` for caller-supplied values.** Several bundled orchestrations (`learn/hello`, `learn/cyberdiner_hello`, `patterns/critique_refine_loop`, `patterns/classify_then_route`, `patterns/parallel_then_judge`, `recipes/comic_strip`, `agents/improver`, `agents/improver_judge`, `agents/meta_orchestrator`) read caller input via the pre-namespace bare form (`{{name}}`), which silently rendered empty against real `-e KEY=VALUE`/`--state`/`use.inputs` input. They now declare `interface.inputs` and reference `{{input.<name>}}`, so `cof check` catches any regression via the existing bare-reference validator. Added a regression test that renders every curated example's templates against a synthetic `input` namespace and fails on any empty render of a declared input.
