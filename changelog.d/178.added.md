- `surrealdb` tool plugin: run SurrealQL (`query` with bound `params`) and record operations (`select` / `create` / `upsert` / `delete`) against SurrealDB from an orchestration. Connection settings come from `runtime.plugins.surrealdb` (`url`, `namespace`, `database`); credentials are read from the environment only (`SURREAL_USER` + `SURREAL_PASS`, or `SURREAL_TOKEN`) so they never reach `runtime.effective_settings` or persisted state. `cof doctor` reports readiness (`library:surrealdb`, `env:SURREAL_*`, `host:<url>`). Install with `pip install circuitry-cof[surrealdb]`. See [docs/plugins/surrealdb.md](docs/plugins/surrealdb.md).
