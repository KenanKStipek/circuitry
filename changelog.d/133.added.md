- **mongodb persistence backend is now exercised against `mongomock`, not just a hand-written fake.** `tests/core/test_mongodb_persistence_mongomock.py` round-trips through `mongomock`'s real `pymongo`-shaped API (`MongoClient`, `replace_one`, `find_one(sort=...)`, its `OperationFailure` hierarchy), asserting the same document shape (`run_id`, `ok`, `error`, `created_at`, `state`) the `jsonl-file`/`sqlite` backends' round-trip tests assert, that an auth failure surfaces as a `RuntimeError` the way the other backends surface theirs, and that the connection string never reaches a persisted document. `mongomock` is a dev-only, pinned dependency (`requirements-dev.txt`) and runs entirely in-memory, so `pytest -q -m 'not integration'` stays fast and database-free. The prior fake-based unit tests are unchanged and remain the fast baseline layer.
