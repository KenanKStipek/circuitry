- **electricity: `-e key=value` reaches `check_for_run`.** The preview
  `electricity` CLI's `-e` flag now passes its inputs through to the
  load-and-check pipeline, for both a plain run and `--dump-ir`: a document
  with a required `interface.inputs` entry (most real orchestrations) is no
  longer rejected outright for lacking one, and `--dump-ir` is usable on it
  once the input is supplied. Declared types are coerced from the `-e` text
  the same way `cof run -e` does (integers accept an underscore digit
  separator, booleans accept the usual lenient words, arrays/objects parse
  as JSON), with Circuitry's own messages on a mismatch.
