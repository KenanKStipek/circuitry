- **Saved state holds each loop's final pass once.** A named loop's `last` is written to `--out`, `--print` and the `--live-state` mirror as a reference to the pass it aliases, `"last": {"$ref": "iter_<N>"}`, instead of a second full copy (nested loops copied it again at every level: 22–52% of a large `state.json`). Run-time reads of `prime.<loop>.last` are unchanged, and a saved state passed back with `--state` (or as `initial_state`, or opened in the TUI's Runs view) has its references relinked, so `last` reads the same as in the run that wrote it. State files that hold full `last` copies still load. (#220)
