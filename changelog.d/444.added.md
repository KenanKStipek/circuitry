- **osp: run electricity with events and live state.** `osp --engine electricity` now detects `--events`/`--live-state` support from `electricity --help`, the same way it already did for `cof`, and launches electricity with both flags when it has them. electricity's own exit codes, failure JSON and preview-marker refusals are read the same way osp already reads `cof`'s, so a run's status, summary line and failure reason come out right on either engine. End-to-end tests (behind `OSP_E2E_ELECTRICITY=1`) and engine-parity golden tests cover the electricity path.
