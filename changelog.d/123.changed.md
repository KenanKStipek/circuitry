- **Complexity signal names: `output_type` → `prompt_type`, `schema_shape` →
  `output_schema`, `structure` → `structural_position`.** The renamed keys show
  up in `circuitry.core.complexity.SIGNAL_NAMES` and `DEFAULT_WEIGHTS`, in a
  `ComplexityScore`'s per-signal breakdown, and in the `meta.complexity.signals`
  mapping a scored prompt effect writes to state — so a CEL condition addressing
  `…meta.complexity.signals.schema_shape.contribution` should now address
  `…signals.output_schema.contribution`. Configured weights are unaffected: the
  new names are the ones `runtime.complexity.scoring.weights` already
  documented and accepted.
