- **`osi`'s `run_tui` loop no longer loses a delivered signal's exit code to a terminal lost in the same tick.** A SIGINT/SIGTERM/SIGHUP osi itself received also forwards a second, synthetic SIGHUP to the engine the moment the terminal check fires in the same tick (`cancel_for_lost_terminal`); if the engine happened to die from that synthetic signal instead of the real one, osi's own exit code reported the terminal's code (129) rather than the user's actual Ctrl-C (130) or SIGTERM (143). The signal osi itself received now always decides the exit code first.
