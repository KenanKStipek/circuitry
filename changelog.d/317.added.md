- **HTTP-family tool failures now include a bounded excerpt of the response
  body.** `http`, `web_fetch`, `webhook`, and `linear` previously failed a
  4xx/5xx response with only the status line (e.g. `HTTP 400: Bad Request`);
  the response body — where a provider's own validation reason usually lives
  — was only kept in `meta.raw.body`. The failure message now appends the
  JSON `error`/`message`/`detail` field when present, otherwise the first
  ~500 characters, redacted the same way `meta.raw` is.
