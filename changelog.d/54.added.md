- TUI library browser now reads every configured library source (`runtime.library.sources`) rather than only the bundled curation library: per-entry source badges, an `s` source filter, `r` to refresh fetchable sources on a worker thread (the view stays usable, and a failed fetch keeps the cached entries under a stale banner), source provenance in the detail pane (repo / ref / pinned SHA / fetched-at for a github source), `enter` to run and `e` to eject uniformly from any source, and source-qualified names wherever two sources claim the same one. An un-fetched github source renders a "press r to fetch" state instead of an empty box.
