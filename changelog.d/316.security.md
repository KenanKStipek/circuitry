- **`runtime.plugins.shell.allowed_commands` is now a ceiling even for a
  *trusted* document.** The effective shell allowlist is always the host's
  pin intersected with the document's own list, never the document's list
  outright — including when the document sets `allowed_commands`, its
  `shell` block, or its whole `plugins` block to `null` or any other
  non-list/non-dict value, which previously dropped the pin instead of
  narrowing it. Closes the one gap #308 left open.
