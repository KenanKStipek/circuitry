- **Two more `network`-tagged tools no longer write a local file for a limited document.** `comfyui`'s `image_output` defaults to `path`, which saves the generated image to `image_dir`, and `s3`'s `mode: get` writes the fetched object to `path` when one is given — both under the `network` capability alone, the same gap `http`'s `save_to` closed (#602). A limited document (a library entry, a `use: ref:`/generated-plan child) must now set `image_output: base64` or `image_output: url`, or omit `path` under `mode: get`; a literal param that still writes locally fails `cof check`, and one only a rendered template, `params_json`, or a profile reveals fails at dispatch instead. A document run by path keeps today's behaviour. electricity doesn't implement either provider yet, so it continues to refuse both with the preview marker regardless.
