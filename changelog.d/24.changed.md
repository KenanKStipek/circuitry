- **TUI cohesion pass — keyboard-complete, one theme, no blank panels.** Every
  control in every view is now reachable without a mouse. `Tab` belongs to view
  navigation, which had left each screen's own widgets with nothing to hand the
  keyboard on: `Ctrl-N` / `Ctrl-B` are the focus ring, so the Run view's adapter
  and model dropdowns, the Library's three panes, and the Runs path box are
  keyboard-reachable for the first time. `Ctrl-Q` joins `Ctrl-C` as a
  priority-bound way out from anywhere. Colours are read from the running
  theme rather than written out as ANSI names, so the run tree stays legible on
  a light terminal, and there is one tick and one cross across the app
  (`circuitry.tui.theme`) instead of two lookalike pairs. The Run view says so
  when there is nothing to run instead of offering an empty dropdown, hides its
  totals footer until there is a run to total, and the Chat transcript opens
  with a line rather than a blank box. Home rows ellipsise at narrow widths
  instead of stopping mid-word, and the footer spends its cells on `? Help`
  rather than on a command-palette hint the overlay already lists. A scripted
  keyboard-only walkthrough (explore → create → profile → run → inspect) is
  checked in as a pilot test, and it is banned from touching a widget directly
  — if a leg of the journey needs a mouse, it fails.
