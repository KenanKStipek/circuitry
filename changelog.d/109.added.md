- **Per-effect routing control in profiles.** `effects.<path>.routing` opts a
  single effect out of the complexity router (`false`) or pins it to a named
  band from `runtime.complexity.routing.bands` (a non-empty string), without
  touching the orchestration or the project/global config. Precedence: this
  effect's own `model` (or a locked run default) still beats a pin; a pin
  still beats the router's own score-based choice. A pinned band name that
  isn't in the run's routing table fails the run before anything dispatches.
  See [Per-Effect Routing Control](docs/profiles.md#per-effect-routing-control).
