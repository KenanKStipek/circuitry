- **OpenTelemetry spans now carry real effect timings and real nesting.**
  The `opentelemetry` runtime plugin used to open and close each effect's
  span inside the same `on_effect_complete` call, so every span reported
  zero duration and none were parented under the run span (or under each
  other) — every effect showed up as its own disconnected trace. Spans now
  open on `on_effect_start` and close on `on_effect_complete` using the
  effect's own `meta.created_at`/`completed_at` timestamps, and nest along
  the orchestration's own structure: a loop's, `use`'s, or dynamic's span is
  the parent of every effect its body runs.
