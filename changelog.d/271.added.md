- **Loop progress, ETA, and run totals.** A running named loop carries
  `meta.progress` = `{done, total, elapsed_s, eta_s}` — `total` is the
  collection length for `each` loops and `max_iterations` (or `null` when
  uncapped) for `while` loops, published pass by pass alongside the rest of a
  running loop's state. In a normal interactive run (`--verbose`, a real TTY,
  never under `--quiet`/`--json`), one updating status line shows the
  currently-running loop's progress (`shots 7/32, ~4 min left`,
  `attempts 2/3`). At the end of a run, `state.runtime.last_run.totals`
  records wall time, effects run, tokens sent/received across every attempt
  (including retries and fallbacks), and cost when some effect reports one —
  printed as one summary line after `Run succeeded` in the normal display.
