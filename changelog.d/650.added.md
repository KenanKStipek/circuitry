  per step, with ghost bars from run history; events/min, decisions and
  in-flight strips on the same axis; a zoom pane for the selected step
  (including an agent's own think/read/edit/bash bands and busiest-tool
  footer); and a "vs usual" pane comparing the run against history. Loop
  rows collapse to one row by default, with `⏎` expanding them into one row
  per pass.
