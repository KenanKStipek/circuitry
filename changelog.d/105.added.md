- **`cof run --explain-routing`.** Prints one line per prompt effect the
  moment before it dispatches: score, the routing band it falls in (or a
  plain statement that routing is off), the model actually about to be used,
  and why — `explicit` when the effect names its own `model:`, `default`
  otherwise. Reads straight off the pre-dispatch meta block `meta.complexity`
  already lands in, so nothing is scored twice and nothing lags the effect it
  describes. Prints nothing when `runtime.complexity.scoring.enabled` is
  false, and is suppressed by `--quiet`/`--json` like the rest of a run's
  prose output. See [Complexity Configuration](docs/complexity-config.md).
