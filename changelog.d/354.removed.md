- **Mustache partials (`{{> name}}`) are no longer part of the template language.** A partial tag would have read `name.mustache` from the process's working directory (chevron's default) — a file read an orchestration never declared. `cof check` now rejects any `{{> name}}` tag as a malformed template, naming the field and the tag; one that only reaches a run anyway (a generated reflector/decompose plan, a `use: inline` child) fails the render under the effect's `on_error` instead, and never touches the file system (#354).
