- **A prompt's `params`, `deterministic`, `timeout_ms`, `assets` and message
  roles now reach the adapter.** They used to be accepted, documented and
  silently ignored. `params` maps `temperature`/`max_tokens`/`stop` to each
  provider's names and passes every other key through (ollama `options`, the
  OpenAI-style and Anthropic request bodies). `deterministic: true` means
  temperature 0, plus a fixed seed on ollama and openai. `timeout_ms` is a
  per-attempt budget capped by the adapter's timeout. `messages` go out as real
  turns with a real system message. Image `assets` (a local path or a URL)
  are sent by ollama, the OpenAI-compatible family and anthropic; state
  records only the path, size and sha256. `meta.finish_reason` is recorded,
  and a reply cut off at the length limit adds a `meta.warnings` entry.
  Adapters that cannot use an option run as before and name what they
  ignored, and `cof check` warns when an effect's adapter cannot send its
  images. Out-of-tree adapters keep working: `generate()` gains an optional
  `options` keyword, passed only to adapters that accept it.
