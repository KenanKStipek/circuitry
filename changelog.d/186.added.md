- **A loop's `each.as` binding and iteration index are now readable from `mode: cel` conditionals, matching what Mustache templates already see.** Inside an `each` or `while` loop's own body, `state.<as_name>` (the loop's own binding — not visible outside that loop) and `state.iter.index` (the current 0-based iteration count) are legal `state.<key>` reads for `if`/`while` CEL expressions; every other `state.<key>` is still a hard error at `cof check` time, named in the error message alongside whatever names an enclosing loop *did* declare. Nested loops shadow the same way Mustache already does — an inner loop reusing an outer loop's `as` name reads the inner binding inside the inner body, and the outer binding again once back in the outer body. See `docs/orchestration-reference.md`'s CEL scoping table and `learn/cel_showcase.yml`'s `filter_scores` loop for a runnable example.
