- **A retried `prompt` or `tool` keeps every attempt.** `meta.attempts`, already recorded for a retried `use` (#663), now covers `prompt` and `tool` effects too: when a pass ran more than once, it lists each attempt, oldest first, with the deciding (last) attempt's own fields repeated at the top level. A tool's entry adds `expect`, `exit_code` and `status_code` (each only when the provider sets it); a prompt's adds that attempt's own `fallback_attempts`, `tokens_sent` and `tokens_received`. The replies and exit codes an earlier attempt produced before a retry started are now in the run's state, written before the backoff wait so `--live-state` and a later attempt's own template/params can read them too (#668).
