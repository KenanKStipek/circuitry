- **replicate, watsonx and comfyui send their request body on stdin.** These adapters/plugins used to put the JSON payload directly on the curl command line (`-d`), which could fail outright on a large body (a base64 image can exceed Linux's 128 KiB-per-argument limit) and was visible in `ps` for the duration of the call. They now use `--data-binary @-` like the other curl-based adapters.
