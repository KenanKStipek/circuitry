- **`timeout_ms` can be read from state: `timeout_ms: {from: <path>, default: <int>}` on `tool` and `prompt` effects.** The value is resolved each time an attempt is dispatched, from current state, loop bindings included, so a step's budget can be decided at run time (by an earlier step, or by a `use` child's inputs) instead of being repeated as a literal on every effect. It must resolve to a positive integer: anything else, or a missing path with no `default`, fails the effect with an error naming the path. `default` applies when the path is missing. Rounding, adapter caps and retries behave as for a literal. `cof check` validates the form (a rooted path string, a positive integer default).
