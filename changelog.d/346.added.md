- **`config.example.json` and `.env.example`.** Two example files ship in the
  package (`bundled/examples/`, in the wheel — `cof setup` prints the
  installed path after writing `config.json`/`.env`) and are linked from the
  configuration guide and reference: `config.example.json` shows the
  documented config keys — adapters, `runtime.plugins.shell.allowed_commands`,
  persistence, `max_concurrency`/`concurrency_groups` — with realistic
  placeholder values, and `.env.example` lists every environment variable a
  hosted adapter reads for credentials and endpoints, one per line with a
  comment, placeholder values only.
