- **`electricity/` — a preview Rust runner for Circuitry orchestrations.** A Cargo workspace (`electricity/Cargo.toml`) alongside the Python package, sharing its version (`[workspace.package] version` kept equal to `pyproject.toml`'s, checked by a test and the release workflow). The `electricity` binary compiles a document and `config.json` and runs it end to end for the content this preview supports, aiming at the same final state, `--live-state` and `--events` output as `cof run`, and refuses what it doesn't support yet with a message naming the refused content and pointing to `cof run` — see `electricity/README.md`'s preview section for exactly what runs and what's refused today, and `electricity/DESIGN.md` for the design. Its CLI recognizes every flag (`-e`, `--out`, `--pretty`, `--live-state`, `--events`, `--profile`) in any position and rejects an unknown one as a usage error (exit 2); the `runtime:` block it merges against `config.json` is the same ceiling-aware deep merge `cof check` uses, rejecting a malformed `runtime.complexity`/`runtime.persistence` block with Circuitry's own message. From this repository's next tagged release on, the release workflow attaches static Linux (x86_64, aarch64) and macOS (aarch64) archives and a multi-arch container image (`ghcr.io/kenankstipek/electricity`) to the GitHub release, marked as a preview.
- **`oscilloscope/` — `osp`, a preview terminal UI that watches and launches a Circuitry orchestration run.** A Cargo workspace (`oscilloscope/Cargo.toml`) alongside `electricity/`, sharing its version the same way. `osp <orchestration> [config.json]` launches a run (on `cof`, or on the electricity preview with `--engine electricity`) and `osp watch <dir | state.live.json>` attaches to one already running; both show a plain-text log, or on a TTY an interactive terminal UI (header, plan tree, log pane), ending on the run's own final status and the engine's exit code. The first Ctrl-C/SIGTERM/SIGHUP cancels gracefully, a second forces it, and `osp` never leaves the engine running after it exits cleanly — see `oscilloscope/README.md` and `oscilloscope/DESIGN.md`. From this repository's next tagged release on, osp's own preview archives are attached to the GitHub release alongside electricity's.
