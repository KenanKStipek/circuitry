- **Backend detection no longer prints any part of an API key.** `cof setup`,
  `cof setup --json`, and `cof doctor` reported the first 8 characters of
  `OPENAI_API_KEY`/`ANTHROPIC_API_KEY` in their "API key set (...)" detail;
  that detail now names the variable only, e.g. `API key set (OPENAI_API_KEY)`.
- **`cof setup` no longer echoes API keys typed at its prompts.** The
  `OPENAI_API_KEY`/`ANTHROPIC_API_KEY` prompts in the setup wizard now pass
  `hide_input=True`, so the key is not shown on the terminal while typing.
