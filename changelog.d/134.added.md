- **`out` as a profile key.** A named profile can now set a default `--out`
  path (`out: runs/result.json`), closing the gap where `--out` was
  documented as a profile-reachable persistence target alongside
  `mongodb`/`sqlite`/`jsonl-file` but had no profile key. Precedence is
  `--out` flag > profile `out:` > default (no file written), matching every
  other profile-overridable setting; relative paths resolve against the
  working directory, exactly like the `--out` flag does today. It stays a
  separate top-level key rather than a `persistence.backend` value — unlike
  the three backends, `--out` has no read-back/`load_latest_state` side, so
  it isn't itself a persistence backend. See
  [`docs/profiles.md`](../docs/profiles.md#precedence).
