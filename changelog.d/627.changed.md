- **`tokens_sent` now means the same thing on every adapter: every input
  token the provider counted, cache reads and writes included.** The
  Anthropic adapter's `tokens_sent` (and the streamed `meta.live.tokens_sent`
  reported from `message_start`) previously counted only `usage.input_tokens`,
  excluding the cache; it now adds `cache_read_input_tokens`/
  `cache_creation_input_tokens` when the response carries them, matching the
  agent CLIs' and OpenAI-compatible adapters' existing behaviour. This raises
  `tokens_sent` (and any total derived from it) for a prompt that hits
  Anthropic's prompt cache; it does not change `tokens_received` or cost.
