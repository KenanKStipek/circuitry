- **SIGTERM now saves state like Ctrl-C.** `cof run`/`run-library`, killed by
  SIGTERM (`kill <pid>`, a process manager, a system shutdown), now take the
  same resumable cleanup path Ctrl-C/SIGINT already did: `finally:` runs
  best-effort, `--out`/the `--last` stash/`runtime.persistence` (if
  configured) are all written before the process exits, and the CLI exits
  `143` (previously it exited with no bookkeeping at all, so a killed run
  could never be resumed). The handler installs only around `cof
  run`/`run-library` themselves, on the CLI's own main thread, and restores
  the previous SIGTERM handling when the run ends — an embedder (the SDK,
  the MCP server, the REST host) driving a run from its own process/thread
  keeps full control of its own signals (#338).
