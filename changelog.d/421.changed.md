- **Retries: one rule for `created_at` and `retries_used`, tools, prompts and `use` alike.** A retried tool's or `use` effect's `meta.created_at` is now the start of its *first* attempt, not its last, so a duration computed from it includes every attempt's backoff — the same rule a prompt already followed. `meta.retries_used` is now set on a failed outcome too, for tools, prompts and `use` alike, not only a successful one; it stays absent (not `0`) when the first attempt is also the last (#421).
