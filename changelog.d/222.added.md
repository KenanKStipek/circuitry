- **`binary` and `env` config for binary-wrapping tool plugins.** `runtime.plugins.<name>.binary` (absolute path, `~` expanded) selects a specific executable, replacing the `PATH` search — for `imagemagick` and the other 17 `GenericSubprocessTool` plugins (`awk`, `docker`, `exiftool`, `gh`, `git`, `kubectl`, `linter`, `mediainfo`, `ocr`, `pandoc`, `ping`, `pytest`, `ripgrep`, `sed`, `7z`, `traceroute`, `yt_dlp`) plus `ffmpeg`. `runtime.plugins.<name>.env` merges process environment variables over the inherited environment. Both are unset by default (no behaviour change); a configured `binary` that doesn't exist or isn't executable fails the tool and `cof check`/`cof doctor` with a message naming the setting and the path, and each tool node's `meta.binary` records the resolved absolute executable. See [docs/plugins/binary-tools.md](../docs/plugins/binary-tools.md). (#222)
