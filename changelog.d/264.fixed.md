- **`environment: prod` in config now actually controls `store_raw`.**
  `resolve_environment()` (used by the SQL persistence runtime plugins and
  `surrealdb`/`clickhouse` to pick `store_raw`'s default) previously read
  only the `CIRCUITRY_ENV`/`CIRCUITRY_ENVIRONMENT` env vars; it now also
  consults `CircuitryConfig.environment` (threaded through as
  `PluginContext.environment`), with the env vars still winning per the
  documented cascade. Tool effects now populate `meta.raw` from
  `ToolResult.raw` (redacted, size-capped — see #262), so the `store_raw`
  switch and the SQL/`surrealdb` `raw` column it gates have something real
  to carry; previously `store_raw` gated a field nothing ever wrote.
