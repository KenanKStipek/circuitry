- **`cof check` warns about a `{{> name}}` reference that cannot be guaranteed to have run yet, because it crosses a `flow: tree` dynamic or `reflector`.** A sibling inside the same `flow: tree` dynamic/`reflector` (or the document's own top-level `flow: tree`), or anything nested under one of that container's children — including inside a loop's body, since a loop's own `flow` never affects the order of steps within one pass — dispatches with no fixed order, so the reference can render `""` at run time even though the name is real. The warning resolves a bare reference with the same scope rules `cof check`'s own name resolution already uses: a named dynamic's/reflector's own children are never bare-visible, even to each other; only the dotted form reaches them. It never changes `ok` or the exit code, and does not fire for `flow: chain`, where order is defined, or for an enclosing container that has already finished before the `flow: tree` container even starts. Ported to electricity's `check_report` with the same text. (#405)
- **`cof check` now also warns on a `{{> <loop>.<step>}}` reference to a loop-body step, a fixed pass, or `last`.** These resolve through the exact same loop state a direct `prime.<loop>.<step>` reference does, and fail the exact same silent way — the existing loop-reference warning now flags both forms. Ported to electricity's `check_report`. (#405)
