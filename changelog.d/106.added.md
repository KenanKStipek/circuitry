- **`on_effect_start` runtime hook.** The counterpart to `on_effect_complete`,
  fired immediately before an effect dispatches with the same canonical dotted
  `effect_path` and the effect's state node — the resolved adapter and model,
  the rendered prompt, and the complexity score once scoring writes it there.
  Optional on the plugin Protocol, so plugins implementing only the completion
  half are unaffected. Embedded callers get it as
  `RunRequest.effect_start_observer`, alongside the existing `effect_observer`.
