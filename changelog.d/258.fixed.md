- **`cof gen` no longer writes output that fails its own `cof check`.** The
  preamble-stripper only matched an uncommented `effects:`/`adapter:` line at
  column 0, so a model echoing the bundled examples' own `# effects:`-commented
  header produced an unparseable `{raw: ...}` fallback file. `cof gen` now
  checks its output with the same checks `cof check` runs before writing
  anything; a document that fails prints the errors, exits non-zero, and
  writes nothing. `--out` now writes the generated orchestration itself
  (default `./<name>.<ext>`), matching `cof wizard --out`; the run's own live
  state JSON moved to a new `--live-state` flag.
- **`cof wizard` no longer crashes with a raw traceback** when a turn's
  orchestration run fails (e.g. a small/quantized model returning non-JSON
  for a schema'd prompt effect). `CircuitryExecutionError` is now caught and
  printed as a clean `Error:` line with exit code 1, matching the existing
  `InvalidDraft` handling in the same command.
- **`cof init` gets a non-interactive mode.** `--yes` (plus `--adapter`,
  `--adapter-url`, `--model` to override any default) accepts the defaults
  without prompting, for scripted/CI use. Its generated `hello.yml` no longer
  silently drops `-e name=...` (it used `{{name}}` instead of
  `{{input.name}}`, with no `interface.inputs` to catch the mismatch); it now
  also needs no model, no network, and no API key to run, using a bundled
  zero-dependency `regex` tool effect instead of a prompt effect.
