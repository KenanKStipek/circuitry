- **`cof gen` no longer writes output that fails its own `cof check`.** The
  preamble-stripper only matched an uncommented `effects:`/`adapter:` line at
  column 0, so a model echoing the bundled examples' own `# effects:`-commented
  header produced an unparseable `{raw: ...}` fallback file. `cof gen` now
  checks its output with the same checks `cof check` runs before writing
  anything; a document that fails prints the errors (escaped against Rich
  markup) and any warnings, exits non-zero, and writes nothing. The
  whole-text parse tried first (for a bare document) is now accepted only
  when every top-level key is one the schema recognizes — a reply like
  "Here's the YAML:" followed by a fenced document otherwise parses, once
  fences are stripped, as a valid mapping with the preamble line as a bogus
  key, which is reported as a warning rather than caught. The check's own
  temp file now uses `tempfile.mkstemp` (same symlink-safe approach as
  `--live-state`) with the suffix chosen from `--format` rather than from
  `--out`'s extension.
- **`cof wizard` no longer crashes with a raw traceback** when a turn's
  orchestration run fails (e.g. a small/quantized model returning non-JSON
  for a schema'd prompt effect). `CircuitryExecutionError` is now caught and
  printed as a clean `Error:` line with exit code 1, matching the existing
  `InvalidDraft` handling in the same command.
- **`cof init`'s generated `hello.yml` no longer silently drops
  `-e name=...`.** It used `{{name}}` instead of `{{input.name}}`, with no
  `interface.inputs` to catch the mismatch. It now also needs no model, no
  network, and no API key to run, using a bundled zero-dependency `regex`
  tool effect instead of a prompt effect.
