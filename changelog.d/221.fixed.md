- **Loop `each.in` accepts an enclosing loop's binding.** `each.in: s.crops` inside a loop whose `each.as` is `s` now passes `cof check` and iterates the bound item's array — the same scope `use` inputs written `{from: ...}` already resolve against (#218/#219) — instead of requiring a child circuit per outer item. A root that names no namespace or binding in scope still fails `cof check`, and the error now lists the loop bindings in scope. (#221)
