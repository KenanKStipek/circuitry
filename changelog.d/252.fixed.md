- **Parallel work is visible while it runs.** Every effect inside a `flow: tree`
  loop or a parallel `dynamic` now fires `on_effect_start` / `on_effect_complete`
  at its full path (`prime.lp.iter_3.step`) as it starts and lands, so effect
  observers, runtime plugins and the TUI see each iteration or branch as it
  happens instead of nothing until the container finishes, and `--live-state`
  shows finished iterations while the loop is still running. Iterations keep
  their isolated state and are still merged in index order. These hooks now
  arrive from worker threads; a plugin that keeps state across calls needs a
  lock. Named `if` and `reflector` effects now fire their own balanced start /
  complete pair, failures included, as `docs/plugins.md` describes.
