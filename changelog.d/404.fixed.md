- **Cancellation flag set from the signal itself.** `cof run`/`run-library` now set a cancelled run's flag (and kill every tracked process) directly off a SIGINT/SIGTERM/SIGHUP, from a dedicated watcher thread, rather than waiting for the signal's own Python-level handler to run on the main thread — closing a rare race under heavy load where a tree-flow branch's next step could start just after cancellation before that handler got a chance to run.
