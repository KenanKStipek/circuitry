- **A Mustache tag no longer renders a Python method.** Inside a section
  whose value is a string (or any other Python object), a tag whose name
  matched one of that value's attributes or methods — `{{#title}}{{title}}{{/title}}`
  over `title: "Intro"` reaching `str.title`, or `{{d.isoformat}}` on a date
  reaching `date.isoformat` — used to render Python's description of that
  bound method (a nondeterministic memory address) instead of falling
  through to the next scope, the way any other missing key does. The
  attribute fallback now resolves only a `date`/`datetime` value's own
  `year`, `month`, `day`, `hour`, `minute`, `second`, `microsecond` fields;
  every other attribute — a method, `int`/`float`'s own `real`/`imag`/
  `numerator`/`denominator`, `tzinfo`/`fold`/`min`/`max`/`resolution`, any
  dunder — is now a miss and falls through, like any other missing key.
  electricity's template engine already had no `getattr` fallback at all
  and so already followed this rule for method names; it now also resolves
  the same named date/datetime fields `cof` does, and its CEL `if`/`while`
  condition evaluation — which never followed attributes at all — is
  unchanged, closing that documented divergence between the two engines.
