- **A Mustache tag no longer renders a Python method.** Inside a section
  whose value is a string (or any other Python object), a tag whose name
  matched one of that value's attributes or methods — `{{#title}}{{title}}{{/title}}`
  over `title: "Intro"` reaching `str.title`, or `{{d.isoformat}}` on a date
  reaching `date.isoformat` — used to render Python's description of that
  bound method (a nondeterministic memory address) instead of falling
  through to the next scope, the way any other missing key does. A name
  that would resolve to a method or other callable is now treated as a
  miss, same as before it falls through; a non-callable data attribute
  (a date's `year`, `month`, `day`, or a datetime's `hour`, `minute`,
  `second`, `microsecond`) still resolves exactly as before. electricity's
  template engine already had no `getattr` fallback at all and so already
  followed this rule for method names; it now also resolves the same named
  date/datetime data attributes `cof` does, closing the one remaining
  documented divergence between the two engines.
