- **`osp`'s terminal UI.** `osp <orchestration>` and `osp watch <dir>` show
  an interactive terminal UI (`ratatui`/`crossterm`) on a TTY instead of
  the plain-text stream: a header (document, engine, run state, elapsed
  time, effects done out of planned, tokens, the innermost running loop's
  ETA), the plan tree (a status glyph, duration, loop `n/total`, and the
  provider or model in a dim colour), the selected row's own details, and
  a log pane with the same lines as `--log` plus the engine's stderr. Keys:
  `↑↓`/`j`/`k` move, `←`/`→` collapse/expand, `tab` switches pane, `f`
  follows the running row, `e` shows errors only, `/` filters, `v` shows a
  value in full, `c` cancels with a confirm (the same as Ctrl-C), `q` quits
  — asking first if a run is going, and in `osp watch` always just
  detaching — and `?` shows help. `--log`, or any non-TTY stdout, keeps
  the plain stream unchanged. Raw mode and the alternate screen are
  restored on every exit path: a normal end, osp's own error, a panic, and
  a forwarded SIGINT/SIGTERM/SIGHUP. See `oscilloscope/README.md`'s new
  "The terminal UI" section and `oscilloscope/DESIGN.md` §6.3.
