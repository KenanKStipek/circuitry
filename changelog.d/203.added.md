- **`params_json` for `tool` effects.** A sibling of `params:` whose value is a
  Mustache template rendered to text and then parsed as JSON, deep-merged over
  `params:`. Lets a tool call (e.g. `mcp` `arguments`, `surrealdb` `data`)
  receive a runtime-built array or nested object instead of only
  Mustache-rendered strings and statically written YAML.
