- **surrealdb plugin: scoped users can authenticate.** `_authenticate()` in
  both the `surrealdb` tool plugin and the `surrealdb` persistence runtime
  plugin now includes `namespace`/`database` in the `signin()` payload,
  trying the most specific scope first (namespace + database, then namespace
  only, then a bare payload) and stopping at the first one the server
  accepts. Previously the payload never carried `namespace`/`database`, so
  only ROOT users could authenticate — a user defined `ON NAMESPACE` or
  `ON DATABASE` was always rejected.
