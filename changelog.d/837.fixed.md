- **A `github` library source now fetches the prompt files its documents reference.** Refreshing a source used to sync only `*.yml`/`*.yaml` files and the manifest, so a document naming a prompt file with another extension (`template: {file: voice.md}`, a declared `prompts:` entry, a message's `content`) would fail once run from the cache — the file was never downloaded. A refresh now also fetches every prompt file one of those orchestrations references, confined to the source's own `path` exactly like a local document's `{file: ...}`; a reference that would escape it is refused rather than fetched. A fetched prompt file is never listed as a library entry, and a changed one still makes a refresh-to-a-new-commit ask for capability consent again.
