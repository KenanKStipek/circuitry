- **The `agent` tool's compact transcript is now JSONL**, written as the session goes rather than only after each turn finishes: one JSON object per line, each with a time, a `turn` header before that turn's CLI call starts, a `tool_start`/`tool_end` pair per tool call (with a short, content-free target and, for a recognised edit/write/multiedit call, line counts), and a `reply` line with the first 300 characters of a reply's text. The file exists, with its first `turn` line, from the moment the first turn's CLI call starts.
