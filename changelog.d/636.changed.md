- **The `agent` tool's compact transcript is now JSONL**, written as the session goes rather than only after each turn finishes: one JSON object per line, each with a time, a `turn` header before that turn's CLI call starts, a `tool_start`/`tool_end` pair per tool call (with a short, content-free target and, for a recognised edit/write/multiedit call, line counts), and a `reply` line with the first 300 characters of a reply's text. The file exists, with its first `turn` line, from the moment the first turn's CLI call starts — so a turn that fails before completing one can now leave a transcript file with real content in it even though `meta.raw.transcript` is still `null` for that attempt (it's removed along with the rest of the session's scratch files unless `params['transcript']` named its own path). A turn failing before the session has an id or an earlier turn has completed still raises instead of returning an `ok: false` result, exactly as before.
