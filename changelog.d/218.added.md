- **`use` inputs by reference, and an opt-in complete record of composed runs.** A `use` input written as `{from: <path>}` passes the value at that path unchanged (array, object, number, boolean) instead of Mustache-rendered text; the path is rooted at `input.`/`prime.`/`runtime.` or at an enclosing loop binding, and `cof check` rejects anything else. With `runtime.state.record_children: true`, each `use` node keeps its child's effects in the final state (as `--live-state` shows them, at every depth, including a failed child's partial record), so a run's `--out` file holds the whole run. Every `use` node now also records `meta.inputs` (what the child received) and `meta.orchestration_sha256` (SHA-256 of the child's YAML). (#218)
