- **A `report` effect.** Renders a message, plus optional `data` selected from
  the shadow state, and publishes it to every watcher — `cof run`'s own
  console (one line, `▸ <message>`, suppressed under `--quiet`/`--json`), the
  `--events` stream (a new `report` line) and the state graph, when named.
  A report never fails the run (no retries, no `on_error`, no capability
  check) and is never counted as work: it never fires a start/end event and
  never counts toward `runtime.last_run.totals.effects_run`. It can go
  anywhere any other effect can — the top level, `dynamic`, `if` branches,
  loop bodies, `use` children and `finally`. electricity implements the same
  behaviour, byte for byte on `--events` and in state. `cof tui`'s plan view
  recognizes the new effect type; its log/status-line/details-pane display
  is left for a follow-up.
