- **Preflight no longer hard-fails a run over a credential an optional effect doesn't need.** `cof check`/`cof run` walked every `adapter`/`provider` an orchestration referenced as a hard dependency, so a single `prompt` effect marked `on_error: skip`/`continue` with no credentials configured for its adapter failed preflight for the *whole* orchestration — even though the effect was designed to skip cleanly and the run would otherwise complete fine. Preflight now classifies an adapter as a **soft** dependency when every effect that uses it tolerates failure: a missing credential downgrades to a warning naming the effects that will skip, `cof check` passes, and `cof run` proceeds with those effects' `value` left `null`. An adapter with even one effect lacking `on_error` handling stays a hard dependency, and the preflight error now names that non-skippable effect directly (useful in the mixed case: one skippable effect and one not, on the same adapter). `--skip-preflight` semantics are unchanged. See `learn/optional_inference.yml` for a worked example.
