- **Changelog fragments — `changelog.d/`.** Every change now ships its changelog entry as a new file, `changelog.d/<issue-or-pr>.<type>.md`, instead of appending to `CHANGELOG.md`'s `## [Unreleased]` section. Because each PR writes a distinct path, parallel PRs no longer conflict on the shared changelog hunk. `python scripts/build-changelog.py` compiles the fragments into the Unreleased section at release time (deterministic order: section, then filename) and deletes them; `--dry-run` and `--check` inspect without writing. `python scripts/check-changelog.py` is the CI gate: code changes must add a fragment and must not edit the Unreleased section, with a `no-changelog` label / `[skip-changelog]` title escape hatch. See [`changelog.d/README.md`](changelog.d/README.md).
