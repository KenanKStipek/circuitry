- **`run_orchestration(..., validate_only=True)` now actually validates.**
  It previously returned `ok=True` before the structural check or compile
  ever ran, so an API caller asking "is this valid?" was told yes for a
  document `cof check` rejects. `validate_only=True` now runs the same
  checks `cof check`/`validate_orchestration` run by default — structural
  check, compile, preflight — and only then stops, before building the
  adapter or dispatching any effect; `RunResult.ok` is `False` for any
  document those checks reject, with the same errors. The CLI (`cof run`)
  always passed `validate_only=False`, so this only affects API/SDK/MCP
  callers that pass `validate_only=True` directly.
