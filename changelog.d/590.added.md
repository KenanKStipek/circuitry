- **`resume: restart` on `dynamic` and `use`.** Under `cof run --resume`, a
  scope with `resume: restart` that did not finish runs from its first
  effect in a fresh state, with its `finally:` as usual, instead of
  reusing its finished effects; a `use` runs its child from its start even
  when its saved record (`record_children`) matches. A scope that finished
  is still skipped, and it holds at any depth (a resumed loop pass, an `if`
  branch, a `use` child). For scopes whose first effects acquire something
  their `finally:` releases (a server, a lock), which a stopped run has
  already released. `resume: continue` is the default and today's
  behaviour. `cof check` rejects the key on any other effect type and any
  other value; electricity validates it the same way. See [Resuming a
  Run](docs/orchestration-reference.md#resume-restart).
