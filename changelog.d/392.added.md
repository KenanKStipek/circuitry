- **The `agent` tool's `transcript` param.** An optional file path (relative to
  `cwd`, or absolute) where the compact transcript is written instead of a
  temporary directory nothing removed — the parent directory is created, and
  the file is appended to across the session's turns, including the repair
  turn. `meta.raw.transcript` points at it once a turn has written to it (`null`
  before then). Without the param, behaviour is unchanged.
