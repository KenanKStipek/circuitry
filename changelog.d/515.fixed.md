- **Ollama/CyberDiner/ComfyUI/SurrealDB preflight no longer leak credentials in `host:{url}` text.** A `base_url`/`expo_url`/`url` carrying `user:pass@` or a credential-like query parameter (`?api_key=...`) is now masked before it reaches a preflight `missing` entry, `cof doctor`, or anything else that prints that text — matching electricity's own Ollama `check()`. A non-string `base_url`/`expo_url` (a misconfigured `runtime.adapters.<name>.base_url: 5`) now reports that same masked text instead of crashing the check.
