- **TUI library browser (`cof tui`, key `1`)** — category tree, entry list and a detail pane rendering the curation manifest (intent, when_to_use, inputs/outputs, primitives, backends, tags, difficulty, example). `/` searches name, intent and tags across the whole library with ranked fuzzy matching and a written-out empty state; `e` ejects the YAML to the current directory, writing the same bytes as `cof eject` and asking before overwriting an existing file. Documented in [`docs/tui.md`](docs/tui.md).
