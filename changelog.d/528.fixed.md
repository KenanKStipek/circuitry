- **`cof check`/`cof run` with a configured allowlist.** An orchestration
  with an inline `use` child holding a calendar-invalid date (`when:
  2024-02-30`) no longer fails with a bare, mislocated `day is out of
  range for month` the moment `enabled_tools`/`enabled_adapters` is
  configured — the pre-run scan that walks `use` children for the
  allowlist check now skips an unparsable inline child the same way it
  already skipped one with a YAML syntax error, instead of crashing. The
  child's own invalid date still fails the run, located and worded the
  normal way, once it actually executes.
