- **electricity:** a tool/`use` param whose YAML/JSON key isn't a string (`yes:`, `1:`) now
  compiles to its own distinct entry instead of being stringified and possibly colliding with
  another key; `--dump-ir`'s `params`/`inputs` shape and non-string-key stringification now match
  `cof run`'s own `json.dumps` rule (`"true"`, not `"True"`), and `--dump-ir` no longer fails
  outright on a `null`/non-finite-float param key (a bytes key still fails, matching `cof run`'s
  own `json.dumps` `TypeError` for one).
