- **A prompt file or document can no longer change between the consent check and the run without being asked about again.** Capability consent — `cof trust`, the check before a run starts, the check for a library child referenced with `use: ref:`, and a `--resume` change check — used to read the orchestration document and every prompt file it references with its own, separate read from the one compilation performed moments later. A file edited in that window was compiled and run with content nobody consented to. Each of those checks now reads a document and its prompt files once, and the compiled document is built from exactly those bytes, so the two can never disagree about what it actually contains.
