- **A prompt file or document can no longer change between the consent check and the run without being asked about again.** The capability-consent digest (`cof trust`, the pre-run gate, and `core.use`'s own run-time check for a `use: ref:` child) used to read the orchestration document and every prompt file it references with its own, separate read from the one compilation performed moments later. A file edited in that window was compiled and run with content nobody consented to. Every one of those surfaces now shares a single read of each file for its whole load/consent/compile cycle, so the digest and the compiled document are always built from the exact same bytes.
