- **A prompt file or document can no longer change between a security check and the compilation that follows, without being asked about again or refused.** Capability consent — `cof trust`, the check before a run starts, and the check for a library child referenced with `use: ref:` — used to read the orchestration document and every prompt file it references with its own, separate read from the one compilation performed moments later. A file edited in that window was compiled and run with content nobody consented to. `cof run --resume`'s own change check (a separate safety check, not part of capability consent) had the same gap in its own fallback for a state saved by a release before #407. Every one of these checks now reads a document and its prompt files once, from the same bytes the compile step itself reads, so none of them can disagree with what was actually compiled and run.
