- **Interrupted runs now agree across engines.** An interrupted `use`
  effect ends `ok: false` in `--events`, with that error and
  `completed_at` recorded on its own node — the same way an interrupted
  `dynamic` already does, including the containers around it and
  `runtime.last_run.totals.effects_run` — instead of reporting `ok: true`
  with its own `start` left unanswered by cof's resuming engine
  counterpart. `cof run --resume` still re-runs an interrupted `use`.
- **A signal during `finally:` no longer skips the rest of cleanup.** The
  first SIGINT/SIGTERM/SIGHUP that arrives while a `finally:` block's own
  step is running lets that step, and every step after it, finish before
  the run stops as interrupted — matching the documented best-effort
  contract instead of killing the running cleanup step outright. A
  second SIGINT/SIGTERM still ends the process at once, as before.
