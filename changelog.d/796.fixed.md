- **Interrupted runs now agree across engines.** An interrupted `use`
  effect and a named `if` branch end `ok: false` in `--events`, with the
  interrupt's error recorded on their own node, the same way an
  interrupted `dynamic` already does, and so do the containers around
  them; they no longer report `ok: true`. A `tool` step killed by the
  interrupt inside a tree-flow loop branch is left unfinished, as it
  already was outside a tree branch: no `end` event and no record, so
  `runtime.last_run.totals.effects_run` agrees too. Every container
  reports the run's own interrupt text (`Interrupted (SIGTERM)`, ...),
  never a worker thread's own cancellation message. `cof run --resume`
  still reruns every one of these.
- **A signal during `finally:` no longer skips the rest of cleanup.** The
  first SIGINT/SIGTERM/SIGHUP that arrives while a `finally:` block's own
  step is running lets that step, and every step after it — including
  one still inside a nested `finally:` — finish before the run stops as
  interrupted, instead of killing the running cleanup step outright or
  abandoning the rest of an outer `finally:`'s own steps. A second
  SIGINT/SIGTERM still ends the process at once, as before. An ordinary
  failure during `finally:` cleanup is still handled as an ordinary
  failure, not reported as this run's own interrupt.
