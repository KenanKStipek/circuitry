- **The `agent` tool records the model it actually ran.** When an `agent`
  effect's `params` set no `model`, `meta.raw.model` and `meta.live.model`
  used to stay `null` even though both CLIs report the model they used —
  Claude Code's `system`/`init` line, pi's own assistant message. Both now
  take that model, updated to the latest the CLI reports over the session; a
  `model` param still wins outright.
