- **Live token accounting for prompt effects.** Ollama, the OpenAI-compatible
  adapter family, `openai` and `anthropic` now stream their replies by
  default (`runtime.adapters.<name>.stream: false` restores the old
  non-streamed request); a running prompt effect publishes `meta.live`
  (tokens sent/received, an estimate while they're still arriving, chars
  received, tokens/sec) the same way the `agent` tool already does, removed
  once the attempt ends. `--events` carries a new `progress` line for a
  streamed prompt's own throttled updates. The `scripted` adapter can
  deliver a reply as a list of `chunks` for deterministic testing of the
  same mechanism.
