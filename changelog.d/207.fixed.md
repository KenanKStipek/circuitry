- **`--verbose` no longer double-prints `use` effects, and their lines now carry loop context.** `use` owned its own start/done/error console lines but was never exempted from the dispatcher's generic per-effect line in `dynamic.py` and `loop.py`, so every `use` result printed twice — once with its `label | elapsed` and once without. `use` is now treated like `prompt`/`tool`: the dispatcher skips its own line and routes `cb_start`/`cb_done`/`cb_error` into `UseRuntime`, so there is exactly one start line and one result line per invocation, and a `use` inside a loop body picks up the same `[N]` iteration suffix prompts and tools already get. The invoking `use`'s display name (name plus any `[N]`) is also threaded into the child orchestration as a label prefix, so a child effect's own line — including inside a nested loop — reads e.g. `read_canvas tile [2] [0]` instead of an unattributed `read_canvas [0]`. `flow: chain` output is unchanged apart from the removed duplicate line.
