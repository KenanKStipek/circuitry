- **A `namespace` param for the `service` tool.** `start`, `stop` and `status` take an optional `namespace` (the same character rule as `name`), keying the record by `<namespace>@<name>` instead of bare `name`. Two orchestrations using the same service name in different namespaces keep separate records and processes: one's `stop` never reaches the other's, and `status` in one namespace never sees the other's record. Ports stay a machine-wide resource — a port held by another namespace's service is still refused at `start`, naming that namespace and name. Without `namespace`, a record (and its default log path) is byte for byte what it was before this field existed. Ported to `electricity` with the same record layout, so a namespaced service one engine starts, the other can find and stop.
