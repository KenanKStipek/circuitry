- **`CIRCUITRY_SYSTEMONE_URL`.** Sets the `systemone` tool's
  `runtime.plugins.systemone.base_url` over the config layer (with `--config`
  too), as `CIRCUITRY_COMFYUI_URL` does for ComfyUI, so a host can point one
  run at its own server without copying the user's config. The other
  `systemone` settings stay in config: the value is checked like `base_url`,
  and a non-loopback URL from it is still refused unless config says
  `allow_remote: true`. `cof` only. See
  [systemone](docs/plugins/systemone.md#host-settings).
