- **`if` branches inside a loop body can see their own earlier steps.** A
  branch step used to render a sibling from earlier in the same branch as
  empty — and a CEL condition inside the branch couldn't see it either —
  whenever the `if` sat inside a loop body, in both `chain` and `tree` flow,
  `then` and `else` branches, and `if`s nested inside a branch. Nothing
  warned; the run exited `0` with silently empty data. `ConditionalRuntime`
  now rebuilds the branch's context after each step, the way a loop body
  already does for its own steps, instead of handing every branch step the
  same snapshot taken before the `if` ran. This also applies to a named `if`
  at the top level: a branch step now shadows a same-named root step inside
  the branch, the same rule a loop body's own steps already followed.
