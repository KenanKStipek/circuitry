- TUI: the Run view draws a complexity score and band beside each prompt effect, populated from the `on_effect_start` hook so the score appears while the effect is running rather than after it lands. Selecting an effect in the state inspector shows the full signal breakdown, strongest signal first, with the signals that dominated the score marked. Effects with no score — non-prompt effects, or any effect when `runtime.complexity.scoring` is off — render as a dash or nothing at all rather than a blank cell, and a terminal too narrow for both drops the score column rather than squeezing the tree.
