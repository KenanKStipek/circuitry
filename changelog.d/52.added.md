- **`github` library source + `cof library refresh`.** A library source can now be a GitHub repository subtree — `{"type": "github", "repo": "owner/name", "ref": "main", "path": "library/", "name": "hub", "token_env": "GITHUB_TOKEN"}` — which makes publish-by-PR to a library repository a first-class consumption path (see [`docs/shared-library.md`](docs/shared-library.md)). Entries are served from a **SHA-pinned cache** at `~/.cache/circuitry/library/<source>/<sha>/` (honours `XDG_CACHE_HOME`; overridable via `CIRCUITRY_CACHE_DIR` or the source's `cache_dir`), read exactly like a folder source. **Only `cof library refresh [<source>]` touches the network** — `cof list / info / run / eject` never fetch implicitly, so they work offline and an unfetched source is an empty source with a "run `cof library refresh`" notice rather than an error. Refresh resolves `ref` → commit SHA via the REST contents API (stdlib `urllib`, no new dependency), re-downloads only when the SHA moved (`unchanged` otherwise), stages the new tree beside the old one, and prunes superseded SHAs. Auth is by environment variable **name**: `Authorization: Bearer $<token_env>` when set, unauthenticated for public repos; the config, the cache index, and serialised state hold only the variable name. 401 / 404 / rate-limit responses are reported with the corrective action attached. See [`docs/library-sources.md`](docs/library-sources.md#github).
