- **`-e` overrides on top of an already-namespaced `--state` file now land
  under `input`.** `-e` values were merged into the loaded state before
  `migrate_legacy_state` ran; when the `--state` file was itself a namespaced
  snapshot (e.g. a prior `--out`), its existing `input` key short-circuited
  the lift and the fresh `-e` key stayed stranded at the root, unreachable
  via `{{input.<key>}}`. `-e` overrides are now merged directly into the
  loaded state's `input` namespace at the CLI merge site, still winning over
  any existing `input.<key>` from the file.
