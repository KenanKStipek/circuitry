- **Authoring mistakes no longer pass validation silently (#261).** A key
  written twice in one YAML mapping is an error naming both lines, in every
  document the runtime loads (files, library refs, `use` children). A key an
  effect or the top level does not know is reported: an error when it is a
  near miss of a known key (`whlie`, `max_iteration`, `adapter` on a prompt),
  a warning otherwise. A loop must set exactly one of `each` / `while`. A
  malformed Mustache template is a `cof check` error, and at run time a
  template that fails to render fails its effect under `on_error` instead of
  sending the raw text. `cof run` applies the same structural check as
  `cof check` before its first effect, and a `use` effect checks a `path:` /
  `ref:` child when it loads it. `cof check` also warns when YAML turned a
  tool's `params.args` entry into a number, boolean or null.
