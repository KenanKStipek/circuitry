- **Prompt text no longer HTML-escapes.** In a `prompt` effect's `template`/`messages`, a `yield` effect's `template`, a declared prompt, or a prompt file, `{{x}}` now inserts the value as it is, like `{{{x}}}` — prompts are not HTML, so escaping only corrupted quoted text, code, JSON and XML-style tags. Every other template (tool `params`/`prompt`, `params_json`, `use` `inputs`/`inline`, asset refs) keeps Mustache's default escaping.
