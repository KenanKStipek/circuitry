- **A `while` loop no longer evaluates its condition before a pass that `min_iterations` already forces.** Previously the condition ran and its answer was discarded on every forced pass — a `mode: cel` condition reading state only the body itself sets logged an "unset state path" warning on every forced pass, and a `mode: model` condition made (and threw away) a model call. Forced passes now run without consulting the condition at all; pass counts are unchanged.
