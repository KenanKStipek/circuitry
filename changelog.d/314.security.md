- **`run_curl()` now sends the request URL off argv too.** The URL travels
  through the same `--config` channel as headers (`url = "..."`, escaped and
  checked for CR/LF/NUL the same way a header value is), so a query-string
  credential (e.g. a search API key in `extra_params`) or `user:pass@` in a
  configured `base_url` no longer shows up in `ps` while the request runs.
  Argv now carries no request data at all for any curl-based adapter or tool
  plugin that goes through `run_curl()`.
