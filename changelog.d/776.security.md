- **The config directory and the `--last` stash are now created with the modes the threat model promises.** `cof` creates `~/.config/circuitry` `0700` and the files it writes there `0600` whatever the umask — previously only `cof setup` applied those modes; the directory's own creation (on the first `cof run`) and the `--last` stash (`last-run.json`, holding every `-e` value of the most recent run) did not, so a first run under a permissive umask left the directory `0755` and the stash `0644`. `electricity` now applies the same modes. The stash is also written atomically (a sibling temp file, `0600` from creation, renamed over the old one), on both engines, so a crash mid-write can no longer leave a stash a reader sees half-written.
