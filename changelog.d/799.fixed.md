- **An interrupt is never lost.** A signal that arrived while a `dynamic`'s
  own `finally:` ran, right after its body already failed and `on_error:
  continue`/`skip` absorbed that failure, used to be dropped whenever
  nothing ran after that `dynamic` — the run ended `ok: true`, exit 0,
  with no trace the signal ever arrived. It now ends `ok: false`, exit
  130/143/129, on both engines, the same way it already did when another
  effect followed. The existing rule stays: with no `on_error` on that
  `dynamic`, its own failure still wins over a later signal (exit 1). A
  `use` wrapping such a `dynamic` no longer re-converts that already-settled
  "failure wins" decision back into a false interrupt once it propagates
  past the `use` — a cof-only parity bug against electricity, which never
  had it.
