- **A named loop's live token sum no longer double-counts its final pass.** `core.dynamic._sum_tokens` (the `dynamic` tree's running token display, and anywhere else that sums a subtree) walked a named loop's `last` alias into its final completed pass a second time — the same dict as that pass's own `iter_<N>` node, not a copy — so a loop of N passes summed to (N+1)× one pass's tokens. It now skips `last` and counts each pass once.
