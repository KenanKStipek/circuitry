- **Adapters can enumerate their models.** A new optional adapter hook,
  `list_models() -> list[str]`, reports what a backend offers — Ollama's
  installed tags (`GET /api/tags`), CyberDiner's tiers, Anthropic's current
  model strings. It is optional in the same sense as `check()`: call it
  through `circuitry.adapters.models.call_list_models`, and an adapter that
  does not implement it (or a backend that is not running) reports nothing
  rather than failing.
- **The TUI run launcher's model dropdown is populated from the selected
  adapter.** Models are fetched on a worker thread, merged with the
  config- and orchestration-derived options, and the list always ends with
  `custom…`, which swaps the dropdown for a free-text box accepting any
  model string — parity with `cof run --model`.
- **`cof list --models <adapter>`** prints the same data from the CLI
  (`--json` for scripts).
