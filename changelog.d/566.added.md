- **`{from: <path>, as: json}` references.** Add `as: json` to a `{from: <path>}` reference — anywhere inside a tool effect's `params` (any depth, list items included) or in a `use` effect's `inputs` — and the param receives the value at that path as compact JSON text (keys in their stored order) instead of the native value, so an object or array can reach a string-only param such as a `shell` `args` entry without a separate `json` effect in `stringify` mode. A `default:` on the reference is applied before serialization. A value JSON can't carry (`NaN`, bytes, ...) fails the effect with an error naming the param's path, and `cof check` rejects any `as` value other than `json`. Without `as`, behaviour is unchanged. The `electricity` runner implements the same modifier.
