- **`cof wizard`** drives the wizard conversation (`agents/wizard.yml`)
  headlessly — clarifying questions, then a validated draft — through the
  same host code the TUI Chat view uses (`circuitry.tui.wizard_host`), so
  both hosts produce identical artifacts from identical input. Turns come
  from `--reply FILE` or plain stdin, so it needs no TTY; the draft goes to
  `--out`, into `--library`, or to stdout. Resolution goes through
  `wizard_path()` → `resolve_bundled()` — the same packaged-`curation/`
  mechanism `cof check` uses — so it works from an installed wheel with no
  repository checkout present. This is distinct from `cof gen`, which drives
  the single-shot `agents/meta_orchestrator.yml`; each command's `--help`
  now says what it drives and points at the other.
  `scripts/wizard-chat`, which only ever worked from a checkout, is now a
  thin wrapper over `cof wizard`.
