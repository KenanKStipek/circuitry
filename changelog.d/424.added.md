- **`osp` (oscilloscope) runs and watches orchestrations.** `osp <orchestration>
  [config.json]` launches `cof` (or, once it runs documents, `electricity`),
  supervises it in its own process group, and prints a plain-text log of
  every effect's status as it runs, ending with the engine's own exit code.
  `osp watch <dir | state.live.json> [--plan doc.yml]` attaches to a run
  started separately the same way. The first Ctrl-C/SIGTERM/SIGHUP forwards
  the signal and logs a cancelling notice; a second forwards it again; still
  running 10s later, `osp` sends `SIGKILL` — it never leaves the engine
  running after it exits, panics included. The plan joins a compiled
  document's effect paths (including `use: path:` children) against what's
  observed; when a document can't be compiled yet, `osp` falls back to a
  plan-free run built purely from observations. `cof run --events` support
  (issue #419) is detected automatically; without it `osp` infers status from
  `--live-state` alone. See `oscilloscope/README.md` and `oscilloscope/DESIGN.md`.
