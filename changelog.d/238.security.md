- **Tool effects redact rendered params before they land in state.** A tool
  effect's `meta.params_rendered` — the Mustache-rendered (and, since #205,
  `params_json`-merged) params actually sent to the plugin — is now passed
  through `cli.redaction.redact()` before being written to the run record, so
  a credential-like key (`api_key`, `token`, `password`, a header named
  `Authorization`, a URL with userinfo, …) is masked in `--out`, the
  `--live-state` mirror, persisted snapshots and runtime-plugin exports. The
  plugin itself still receives the unredacted value — only the stored copy
  is masked.
