- **`cof run --events <file>` / `cof run-library --events <file>`.** Writes a
  JSONL stream of effect starts and ends as the run goes — one line per
  `run_start`, `dispatch`, `start`, `end` and `run_end` event, written and
  flushed the instant it happens. Shows what `--live-state` cannot: a running
  tree branch or `use` child (invisible there until it finishes) and a
  running chain leaf (visible there only if a coalesced write happens to
  land while it runs). See the orchestration reference's "Watching a Run"
  section for the format. (#419)
