# Versions of every library whose text or behaviour the conformance suite
# (tests/conformance/) and electricity/scripts/generate_*.py compare against:
# cof's own loaders, renderers and evaluators call into these, so an unpinned
# upgrade could change a committed expected-output file, or a conformance
# case's comparison, with no change in this repository. Includes the
# libraries underneath the ones cof depends on directly (jsonschema's own
# referencing/jsonschema-specifications; cel-python's own lark/google-re2/
# pendulum), since those float on an open range too.
#
# CPython 3.11 is the reference interpreter for anything Unicode- or
# exception-dependent (tests/conformance/README.md); these pins are what CI
# resolves `pip install -e ".[tools]"` to on 3.11 today. quality.yml and
# electricity-generated.yml install Circuitry with these as constraints
# (`pip install -e . -c electricity/scripts/generator-constraints.txt`).
#
# To bump one: change it here, then regenerate and review the diff --
# `python scripts/generate-conformance-cases.py` (repository root) and every
# `electricity/scripts/generate_*.py` (without --check) -- before committing.
